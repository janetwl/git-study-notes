# 导论(全书使用法)

定位:全书的说明书——交代写作动机(批判性思考被教育长期忽视)、三大部分分工、以及"这本书该怎么用"。

## 核心论点

- 写作背景:作者指出近几十年的教育倾向是重主观与感觉、轻客观与思考,本书旨在系统补上批判性思考这一课。
- 三部分定位(全书导航的骨架):
  - 第一部分"背景":理解个性、思考、真理、知识、观点、根据、论证等重要概念,并克服阻碍批判性思考的态度和观念(第1-7章)。
  - 第二部分"易犯的错误":识别和避免思维当中最常见的谬误(第8-13章)。
  - 第三部分"策略":获得解决问题和议题的技巧,包括确认和克服个人智识弱项,以及观察、澄清问题、探究、评价根据、分析他人观点、作出合理判断(第14-19章)。
- 使用法(作者明确授权):
  - 不必逐页顺序读;需要时可径直翻到后面章节查解释(导论举例:遇到没把握的术语如"相对主义"就查索引;剽窃的规范在第二章末"避免剽窃";检索技巧在第十七章)。
  - 每章末尾有应用练习;前十三章的练习都围绕"一个有见识的意见发生分歧的议题"设计,供实战考察。

## 辅导提示

- 用户问"这本书讲了什么/从哪章看起" → 直接用三部分定位答:概念与态度(背景)→谬误识别(易犯的错误)→操作技巧(策略)。
- 用户带着一个具体思维困惑来 → 先判断它属于"态度/概念障碍"(第一部分)、"正在犯的谬误"(第二部分)还是"缺操作流程"(第三部分),再进对应章节的框架。
- 用户想只挑实用方法 → 引导到第三部分(策略篇)的方法卡,同时提醒作者立场:技巧须与第一部分的态度转变配合,不然只是换了种"不假思索"。
