# 第五章 你的观点有多少根据?

定位段:本章解决"观点凭什么值得被认真对待"的问题——拆穿"我有权拥有自己的观点"的滥用,区分喜好与判断,给出观点可错性的证据链,并交付一套提高观点质量的可操作程序。它是第五章至第七章"证据与论证"方法论三部曲的入口。

## 核心论点

### 1. 先分清:你表达的是喜好还是判断?
- "观点"有两种用法:
  - **个人喜好**:标准是低要求的个人偏好(艾格尼丝觉得雷金纳德英俊、热狗加什么酱)——对此不存在有意义的争辩,"差别万岁"。
  - **慎思的判断**:最高法院对争议案例的见解,"经过深思熟虑的判断,是在彻底调查和审议后艰难作出的判断"。
- **本章定义(可检验)**:在批判性思考背景下,观点指**判断的表达**而不是喜好的表达。
- 边界情形:朋友说"这是一部精彩的电影"——可能意为"我喜欢它"(不可辩),也可能意为"它达到了很高的电影制作水平"(可辩,你可以引用这部电影未达到的具体电影标准质疑她)。
- 辅导/自检第一步:任何"我有个观点"出现时,先问这是哪一类。

### 2. "有权持有"≠"一定正确"
- 自由社会保障持有和表达观点的自由,但"人们拥有不可剥夺的权利去思考自己的想法"不等于"他们思考的想法将都是合理的"。
- 按观点行事受法律限制:**只有当不伤害他人时,我们才可自由地根据自己的观点行事**(信仰疗法者致糖尿病男孩死亡、父母被控谋杀的案例)。
- 批判性思考基本原则:各种思想很少具有同等的性质——方案从切合实际到不切实际、信念从有根据到无根无据、论证从符合逻辑到不合逻辑、观点从有见识到无见识不等;**任务是把较有价值的与较无价值的区别开来,并最终确定最佳者**。

### 3. 观点会出错:三层证据
1. 日常实例:周末酗酒者自认不算酒鬼;油表归零仍开高耗油车者;16岁退学者以为早进就业市场更稳——"无论如何深刻地、真诚地持有这些观点,他们还是错了"。
2. 无意识影响:即使"特别努力地进行客观判断"也可能出错——咖啡标签实验(同一咖啡贴棕/黄/红三种标签,品尝者分别说"太强烈""索然无味""恰到好处"),人被标签颜色无意中影响(呼应前章的感知/品尝者内容)。
3. 专家也会错(历史案例库,供引用):
   - 古代医学:头痛因脑壳内恶魔,开颅放恶魔、牛脑山羊粪配方;
   - 1700年代天花接种:多数权威专家斥为胡闹(含富兰克林、哈佛医学院创立者),对的反而是没有医学学位的波尔斯顿;
   - 1980年诺贝尔奖细菌学家罗伯特·科赫宣称治愈结核病的物质,注入后加重病情甚至致死(原文如此,人名年代存疑);
   - 1904年心理学家斯坦利·霍尔:妇女艰苦脑力活动会丧失乳腺功能与母性爱好;
   - 1919—1922大都会博物馆按专家鉴定购入的17个"3500年埃及古墓"金器,1982年被证实是20世纪赝品;
   - 1928二氧化钍胶体造影剂,19年后得知小剂量也致癌;1959沙利度胺致畸;
   - 1973雷达绘图推翻金星"光滑表面"旧说;
   - 1980—90年代"共同依赖"概念:研究者戈姆伯格检验其科学基础,"无、不存在、什么也没有……只有描述,仅凭印象的陈述";
   - 胃溃疡"压力说"被马歇尔的细菌成因说推翻;
   - 1999帕里什颈骨电脑模型:大恐龙不可能把头伸过身体水平线,《侏罗纪公园》镜头错误;
   - "纤维降胆固醇、防结肠癌"被后续医学研究推翻;
   - 赛米诺对犯罪两大主流成因说(恶劣环境说、情绪失常说)同时质疑:罪犯本身才是原因。
- 结论态度:"不可能知道未来的研究人员将推翻我们这一代专家的哪些观点。但我们可以确定,某些观点将被推翻。而这些很可能是在当代看起来无懈可击的观点。"

### 4. 错误来源四分类(弗兰西斯·培根"假象"说的改写)
1. 人的本性普遍易错(有选择地感知、仓促判断、过于简化复杂现实);
2. 与个人思维习惯/偏见/信仰有关(习惯只想某个被偏见族群的最坏情况);
3. 人际沟通与语言的局限性(不当表达引导他人形成错误印象);
4. 时代风气中的错误(祖辈时代不质疑权威;我们时代只承认自己)。

### 5. 洛克"最容易犯错的人"三型 + 作者增补第四型
- 第一型:根本不推理,像周围人(父母、邻居、牧师)一样思考行动,逃避自己思考的困难;
- 第二型:决意让激情而非理性统摄生活,只接受支持其偏见的推理;
- 第三型:真诚遵循理性但缺乏准确全面的判断力,只跟同一类型人谈话、读同一类书,只接触一种观点;
- **第四型(作者增补)**:对已经形成的观点从不费心再次检验的人——"这些人是所有人中最容易出错的,因为他们拒绝了在新证据面前纠正错误的所有机会"。

### 6. 道德观点并不例外:三条判断标准
"你的观点对你是对的"式道德主观主义"完全肤浅"(无人会给恋童癖挂"对他却是对的"横幅;交警不会表扬按自己道德信念生活的醉驾者)。伦理规范、法律体系都是道德判断的结果,同样可错。提高正确道德判断可能性的标准:
- **义务**:对行为的限制,要求做/不做某事;最明显是正式协议(合同),还有职业与商业义务、友谊与公民义务;**义务冲突时优先最重要的一个**。
- **理想**:卓越的观念,带来自身之内与他人之间更大和谐的目标,有助于尊重他人的特定概念(诚实、正直、正义、公平);**理想冲突时优先最重要的一个**。
- **结果**:行为产生的有利和/或有害后果,检验须覆盖各方面:个人/社会、身体/情感、当下/永久、有目的/无目的、明显/微妙、可能/概率/确定;**选导致有利结果的行为;结果混合时,选导致较大善或较小恶的行为**。

### 7. 有见识观点的资格标准
- 为什么要咨询专家(三个示范议题):大麻作用问研究它的科学工作者而非吸食者;类星体问天文学家而非街角路人;鲸的声呐(座头鲸滴答/吱吱/砰砰/叽嘎声、100—111分贝、25000英里)问研究鲸的人。
- 咨询专家获得的是:扩展视域、看到自己看不到的细节、意识不到的事实、减少犯错可能。"寻求正确性担保的做法是愚蠢的——不存在这样的担保。"咨询不是依赖性,而是高效和明智。
- **有见识观点三要件**:
  1. 以更加坚实的事实为基础——比熟悉程度、持有时长、"我希望如此"的假定权利更坚实;
  2. 建立在对证据仔细考虑的基础之上;
  3. 正式表达观点时应当恰如其分地支持它。
- 比例示范(马歇尔与塔克论美国教书不受尊敬的原因在于教师多为妇女):追溯历史发展、引用行政指令和哲学陈述、提供雇用模式(1870年59%→1920年86%妇女)、阐述课程转变、比较薪水统计、显示谈判地位——**观点陈述仅占一两句,支持细节占若干段落、页面甚至整章**。

### 8. 形成正确观点:三步技巧
1. **了解观点是如何形成的**——感知无法停止;不能控制时,心智以"非批判的默认模式"运作。两种模式对照表:
   | 非批判的默认模式 | 批判性思考模式 |
   | --- | --- |
   | 感知 | 感知 |
   | 允许"脑中出现"一种观点 | 考察该议题 |
   | 集中于支持该观点的信息 | 考虑其他观点 |
   | 接受该观点 | 决定哪种观点是最合理的 |
2. **抵制把你的观点看作事实的诱惑**——观点一旦形成就像父母与孩子般联结,越记住、越表达,联结越强,质疑它变得难以想象;谨慎做法:质疑任何观点(包括你珍爱的)。
3. **监控你的思想以防止非批判性默认模式的掌控**——每当开始形成印象时执行爱比克泰德暂停法:"不要让你被生动的印象弄得神魂颠倒,而是说,'印象,稍等片刻。让我看看你是什么以及你代表什么。让我尝试[检验]你]。"
- 收益:你将可控制自己的观点,这比让它们控制你具有相当大的优势。

## 逐字摘录

- "在批判性思考的背景下，观点 这个术语指的是判断的表达而不是喜好的表达"
- "只有当不伤害他人时，我们才可自由地根据自己的观点行事。"
- "批判性思考的基本原则就是，各种思想很少具有同等的性质。问题的解决方案从切合实际到不切实际之不等，信念从有根据到无根无据之不等，论证从符合逻辑到不合逻辑之不等，观点也从有见识到无见识之不等。批判性思考的任务是把较有价值的与较无价值的区别开来，并最终确定最佳者。"
- "然而，无论如何深刻地、真诚地持有这些观点，他们还是错了。"
- "人们无意中受到了标签颜色的影响 。"
- "关于道德问题的看法，就像其他看法一样，可以是正确的或不正确的。"
- "义务是对行为的限制，要求我们做或不做某事。"
- "从一般意义上说，理想是卓越的观念，是带来自身之内、与他人之间更大的和谐的目标。"
- "结果是既影响行为人自己也影响他人的一个行为所产生的有利和/或有害的后果。"
- "对于洛克的这个清单，我们还应增加一种类型：那些对已经形成的观点从不费心再次检验的人。这些人是所有人中最容易出错的，因为他们拒绝了在新证据面前纠正错误的所有机会。"
- "不可能知道未来的研究人员将推翻我们这一代专家的哪些观点。但我们可以确定，某些观点将被推翻。而这些很可能是在当代看起来无懈可击的观点。"
- "一个观点要被看作是有见识的，就必须以更加坚实的事实为基础，即比我们对这个观点的熟悉程度、我们持有该观点的时间长度或我们思考自己所希望的东西的假定权利还要坚实。它必须建立在对证据仔细考虑的基础之上。"
- "正如本例所展示的，在最负责任的观点表达中，观点陈述仅占了一两句，而支持的细节则要占据若干段落、页面甚至是整个一章。"
- "当你不能控制时，你的心智体系就以非批判的默认模式运作。"
- "一旦你形成了一种观点，就自然地与它联系在一起，就像父母与孩子联系在一起一样。"
- "不要让你被生动的印象弄得神魂颠倒，而是说，‘印象，稍等片刻。让我看看你是什么以及你代表什么。让我尝试［检验］你’。"
- "你将可控制自己的观点，而这比让它们控制你具有相当大的优势。"

## 辅导提示

- 用户说"我有权保留我的看法,别争论了" → 先照出隐含假设(把"持有自由"偷换成"免于检验"):喜好 vs 判断的分界;个人口味无需证据,慎思判断必须给出根据。反问:"你这句话里的'观点',是'我喜欢'还是'我认为这是对的'?"
- 用户拿亲身经历当普遍结论("我认识一个XX,所以XX都……") → 用"观点可错性"+咖啡标签实验+洛克第三型(只接触一种观点)引导;让他自己数样本:支持概括需要多少个、哪些种类的例子?
- 用户问"专家意见互相打架,到底信谁" → 有见识观点三要件:对特定问题有无具体专业知识、结论是否与证据一同给出(1-2句观点配整页支持的比例检验)、是否被同行确认;再用"专家也会错"案例库校准期待——要的是更可靠的意见,不是正确性担保。
- 用户陷入道德之争("这事见仁见智") → 义务/理想/结果三清单逐条走:涉及什么义务?冲突时哪个最重要?涉及什么理想?结果的六个维度(个人社会/身体情感/当下永久/有无目的/明显微妙/可能概率确定)列出来,混合结果选"较大善或较小恶"。
- 用户抱着一个珍爱观点不放 → "抵制把观点看作事实的诱惑"+爱比克泰德暂停法实操:让他把印象写下来,对它说"稍等片刻",先执行对照表的中间两列(考察议题、考虑其他观点)再决定接受。
- 思考练习(改编自本章应用练习9):陈述一个你或你认识的人曾持有、后来证明错误的观点,并解释它为什么错、当时的证据属于哪一类?
- 思考练习(改编自本章应用练习5):给一段含"我的看法是……"的文字,让用户判断作者强调的到底是偏好陈述、慎思判断、随意看法、固执立场还是五种里的哪一种,并说明推理。
- 思考练习(改编自本章应用练习10之一,如"周末狂饮属于酗酒性质吗?"):让用户写一两句观点陈述,然后逼他补出"若干段落"的支持细节,对照马歇尔-塔克示范检查支持比例。
- 思考练习(改编自本章应用练习8弗雷德对话):"我不需要任何根据,因为它是我的观点"——让用户指出这句话违背了本章哪个观念,并替弗雷德重写一个不违背的回应。
