# 第七章 什么是论证?

定位段:观点(第五章)要有据(第六章),据要组织成论证。本章把"论证"从争吵和辩论赛中解放出来,定义为"支持一个判断的推理思路",交付论证的结构术语、四条逻辑评价原则、标准化的提问格式,以及五种困难论证(超长、成分不明、多前提、对立双方、隐蔽前提)的处理指南。

## 核心论点

### 1. "论证"的三种含义,只取第三种
- **争吵**("一场真正的尖叫比赛"):更多由情感而非思考构成,是自我之间的冲突,时常退化为无理智的瞎扯——与批判性思考无关。
- **两人或更多人之间的意见交流**(正式辩论):理想上是"具有不同见解的人一起工作以达到对某个议题更深刻、更准确理解的合作性努力",人人都愿意被证明是错的,没有输家——与批判性思考有关联,但自我不易压制,我们常被训练成相信论证像体育竞赛必有赢家输家。
- **支持一个判断的推理思路**("约翰对死刑问题的论证比莎莉的更具说服力"):聚焦个体贡献的质量——**本章与全书的主要关注点:对个体的、你自己的以及其他人的论证进行评价**。
- 自检用法:判断一场对话是争吵还是论证(应用练习1的电视脱口秀任务)。

### 2. 论证 = 没有数学符号的文字方程式
- 数值方程式 1+1=2;文字方程式示例(三段论模板):
  - 法律禁止老师在公立学校带领全班同学进行祈祷。
  - 维诺娜带领全班同学在公立学校的课堂上进行祈祷。
  - 因此,维诺娜违反法律。
- 可复杂可简单:结论可从许多前提(断言)得出;一个不正确的断言会像数字表中一个错误数字毁掉总和一样造成错误结论(唯一例外是纯属巧合:前提缺乏事实基础的论证结论可能碰巧为真——脚注里佛罗里达皮肤癌的例子)。
- 与数值方程的关键差别:**论证通常更复杂、更难检验**——维生素C与感冒、电视暴力与现实暴力、肯尼迪案、拉姆齐案等,证据尚不完全,存在分歧空间。

### 3. 论证的结构与识别
- 两个术语:**前提**与**结论**。
- 结论指认词:"因此"及同义词"所以""从而";
- 无指认词时的检验问句:**"其他断言支持或加强了哪一个断言?"**——被支持/加强的那个就是结论。

### 4. 逻辑学家评价论证的四条基本原则
1. 前提要么**真**,要么**假**(正确或不正确);
2. 衔接前提与结论的推理要么**有效**,要么**无效**(有效的标准:所陈述的结论、而且只有这一结论必须是在逻辑上从前提推导出的);
3. 正确的前提 + 有效的推理 = **合理的**论证;
4. 或者是不正确的前提,或者是无效的推理,将使得一个论证是**不合理的**。

### 5. 评价论证的基本方法(标准提问格式)
- 一句话方法:**判定前提是真还是假,以及从前提导向结论的推理是否有效**;两个标准都满足,论证就是合理的。可能需要做一些调查确定前提真伪。
- 格式:对每个前提提出"这是真的吗?总是如此吗?"式问题;对结论固定提出两个问题:**"该结论在逻辑上是从前提中所陈述的事情中推导出来的吗?还有任何其他结论也同样可以从前提中推导出来吗?"**
- 四个示范论证(可直接当教学模板):
  1. **苏格拉底**(所有人都会死/苏格拉底是人/因此苏格拉底会死):两前提真,结论是唯一可推出的结论——正确(合理)。
  2. **健美是不是体育**(强体力运动皆体育/健美含强体力运动/因此健美是体育):第一前提假(搬钢琴是剧烈体力运动而非体育)——不合理。**关键教训:表明论证不合理≠证明结论为假**(健美仍可能应归体育,只是需要别的合理论证)。
  3. **测谎器与布鲁诺**(罪人通常过不了测谎/布鲁诺没过/因此布鲁诺有罪):两前提可真,但**前提没有提供充足证据**得出结论——还需要知道无辜的人是否也不能通过测谎;若是,布鲁诺可能是无辜的。(有效性/充分性双查的示范)
  4. **简成功了所以简工作努力**(成功属于努力工作的人/简成功/因此简工作努力):第一前提不完全真(有人努力仍失败、有人不努力也成功)——因前提不正确而不合理。
- 双面倾听原则:对正反两个论证都印象深刻是常事(2000年大选布什可卡因风波:一边说"用过即虚伪",一边说"用过的人更懂毒品危险,酗酒者比禁酒者更有资格谈酒精"——两组专家论证结构互驳)。**当你能倾听双方、至少考虑对方观点的各个方面批判时,评价最有效。**

### 6. 比较困难的论证:五种情形 + 处理指南
1. **论证超过一个段落** → 提问和回答之前先做总结;风险是歪曲原意,仔细做可避免。
2. **不确定哪些是前提、哪个是结论** → 问:这个人究竟想让你接受什么思想(这就是结论)?为支持它提出了哪些理由(这些就是前提)?
3. **两个以上前提** → 对每一个前提提问并回答,每次只对付一个;排除所有不相关的前提后,判定结论是否逻辑上从剩余前提推出、是否唯一结论;若可得多个结论,判断所陈述的这个是不是最合理的。
4. **两个相互对立的论证都不具说服力(即使有一个技术上合理)** → **寻找第三个选项,往往从每一方抽取一点**。示范:公立学校展示十诫之争——肯定方(应鼓励道德价值观/展示十诫鼓励道德价值观/应展示)对否定方(不应优先对待任何宗教团体/展示将使基督徒犹太人优先/不应展示),第三选项=展示所有版本的十诫及任何宗教或世俗道德价值观列表(容纳所有观点不再像忽视所有观点那样冒犯,还强调道德价值)。
5. **论证含隐蔽的前提** → **评价之前先把它们找出来**。隐蔽前提准确时无害;不准确时暗中破坏论证。四个分解示范(陈述前提/隐蔽前提/结论各配检验问题):
   - "他们决不应该结婚——在求婚过程中，他们彼此没有感受到强烈的肉体吸引。" → 隐蔽前提:"强烈的肉体吸引是婚姻最好的，或许是唯一有意义的基础"(直接追问这个前提);
   - "显然，莫顿在学校未充分发挥学习潜能的原因是——他几乎没有自尊心。" → 隐蔽前提:"自尊心是为达致目标所必须的";结论句实际意思是"这解释了为何……";
   - "应当禁止这本书,因为它让儿童接触暴力" → 隐蔽前提一:"接触暴力是有害的"(注意无限定语如"有时"时,"总是"暗指普遍术语——把问句改写成"接触暴力**总是**有害的吗?");隐蔽前提二:"对这类材料,禁止是最恰当的反应";
   - "饮用纯净水是健康的，“原始山峦”（Pristine Mountain）的水是纯净水，所以，饮用它而不是自来水对我的身体有好处。" → 陈述前提两条 + 隐蔽前提:自来水龙头里的水不是纯净水。
   - 长度警告:以为段落越长隐蔽前提越少是诱人但错误的想法——**段落越长,越难确认这些前提;无论多长都要警惕**。

### 7. 态度配套:把第一印象当"可能性"而非"确定性"
- 认为第一印象不会错 → 非批判接受 → 找支持证据、拒绝质疑证据、狂热辩护 → 易自欺或被操纵。
- 尝试性地看待第一印象(有趣的可能性,不是确定性),作决定前与其他思想比较 → 不易愚弄自己或被他人欺骗。(呼应第七章开头"错误论证"的来源之一)

## 逐字摘录

- "由于争吵更多的是由情感而不是思考所构成，而这种情感是自我之间的冲突，时常退化为无理智的瞎扯，所以论证 的这种定义与批判性思考没有什么关系。"
- "从该术语的这个意义上看，论证在理想上是具有不同见解的人一起工作以达到对某个议题更深刻、更准确理解的合作性努力。"
- "在这第三种意义上，论证 意味着“支持一个判断的推理思路”。"
- "把一个论证看成是一种没有数学符号的文字方程式，也许是有用的。"
- "而且，就像某列数值中有一个不正确的数字将导致错误的总数一样，拥有一个不正确的断言也会造成错误的结论"
- "（因此 这个词和诸如所以 、从而 这些同义词经常用来指认结论。）在不使用这些词的地方，你通常可以借助回答下述问题来确认结论，即其他断言支持或加强了哪一个断言。"
- "1．前提要么真 ，要么假 （正确或不正确）。"
- "2．衔接前提与结论的推理要么有效 ，要么无效 。（要成为有效的，所陈述的结论、而且只有这一结论必须是在逻辑上从前提推导出的。）"
- "3．正确的前提加上有效的推理等于合理的 论证。"
- "4．或者是不正确的前提，或者是无效的推理将使得一个论证是不合理的 。"
- "评价论证的基本方法可以简述为：判定前提是真还是假，以及从前提导向结论的推理是否有效 。如果两个标准都满足，那么该论证就是合理的。"
- "例如，如果你认为自己的第一印象是不会错的，那你就可能非批判性地接受它们，并寻找证据支持它们，而拒绝质疑它们的证据，然后狂热地为它们辩护。这种方法使得你容易自欺欺人或被他人所操纵。"
- "请注意，表明这个论证之不合理性并不证明健美不应被划归体育。也许可以提出一些会被证明为合理的其他论证。"
- "我们需要知道一名无辜的 人是否不能通过测谎器测试。如果是这样，那布鲁诺可能是无辜的。"
- "请记住，当你能倾听双方或至少考虑人们对构成对方观点的议题的各个方面所进行的批判时，你对任何论证的评价有可能是最有效的。"
- "那就寻找第三个选项。这个选项往往是从每一方抽取一点。"
- "当一个论证含有隐蔽的前提时 ，在你进行评价之前先把它们找出来。构想并表达论证时，隐蔽的前提显然意味着还未认识到的思想。当隐蔽的前提准确时，就不会有什么坏处；但是当它不准确时，就会暗中破坏论证。"
- "认为段落越长，所包含的隐蔽的前提就可能越少，这是挺诱人的想法，但事实并非如此。"
- "事实上，段落越长，就越难确认这些前提。无论你评价（或撰写）的段落长度如何，你都要警惕隐蔽的前提。"

## 辅导提示

- 用户在争论中说"你这人就是强词夺理/我们聊不到一起" → 先问:这是争吵还是论证?争吵是自我冲突,论证是"支持一个判断的推理思路";把对话拉回文字方程式格式——让用户把对方的话重写成 前提+前提+因此+结论 的三段式,写不出来说明连结构都没抓到。
- 用户丢来一段社媒雄辩/长文让你"评评理" → 按五种困难情形分诊:超一段先总结;分不清结论就问"他想让你接受什么思想";多前提就一次只对付一个;遇到显然、当然、谁都知道一类措辞处揪隐蔽前提(用莫顿、纯净水模板:把没说的那句写出来,直接问它真不真)。
- 用户的观点其实建立在未明说的假设上 → 本章最有用的教练动作:不攻击他的结论,而是把隐蔽前提摆到桌面让他自己判定("强烈的肉体吸引是婚姻最好的，或许是唯一有意义的基础吗？")。示范问题包来自四个分解例子。
- 用户被驳倒后情绪化("他说得对,我输了") → 两条解药:①论证理想是合作性努力,人人愿意被证明是错的,没有输家;②一个论证被证明不合理≠结论为假(健美例):你可能只是用一个坏论证支持了一个对的观点,试着替这个观点另造一个好论证。
- 议题双方各有道理、用户选边站 → ①双面倾听原则(布什例子:两组专家论证互驳);②对立双方都不服时执行"寻找第三个选项,从每一方抽取一点"(十诫展示案例的解法示范)。
- 用户问"怎么判断推理是不是有效" → 两个固定问句:"该结论在逻辑上是从前提中所陈述的事情中推导出来的吗?还有任何其他结论也同样可以从前提中推导出来吗?"用测谎器案例讲"前提都真但推不出"的情形(布鲁诺可能无辜)。
- 思考练习(改编自本章应用练习1):回忆最近一档讨论争议议题的脱口秀/直播对谈,判断它是争吵还是论证,并引用本章三种含义逐条解释。
- 思考练习(改编自本章应用练习4之一,如"两个未婚成年人谈恋爱没有什么错，所以，教授约会18岁以上的学生是可以接受的。"):让用户补齐这个论证省略的前提,再逐一提问判定。
- 思考练习(改编自本章应用练习4h"乞讨是一种言论方式。言论是受宪法保护的。因此,乞讨是一种不能被剥夺的权利"):先写成标准三段,再检验:第一前提真吗?"言论方式"的界定是不是隐蔽前提?结论是唯一可推出的吗?
- 思考练习(改编自本章应用练习2):选一个近年公共议题,检索一篇"介绍某个观点而非只报道事实"的文章,用本章格式(每前提一问+结论两问)写一篇评价。
