# 第九章 立场的错误

定位:进入"处理具体议题"之前,先清理头脑中长期存在的关于现实的错误观念——立场错误。它们在具体问题尚未出现时就塑造你评价问题的态度和习惯、制造偏执的预期,而且往往无自知,除非专门审视自己的思维模式。本章是全书的"世界观体检清单":六个具体错误(无根据的假定、要么/要么观念、盲目遵从、绝对主义、相对主义、支持或反对变化的偏见),外加一个总括性概念"视角匮乏"。承接第八章("我的更好"是它们的温床,反变化偏见直接由它驱动),为第十章程序错误铺路。

## 核心论点

### 总比喻与总纲

- 立场错误=严重扭曲却无自知的镜片:不在鼻子上,在头脑中;一旦易犯,必不时产生危害,塑造评价问题的态度习惯,并产生让思想偏执的预期。
- 药方总则:定期评价自己的思维模式,识别→根除。

### 0. 视角匮乏(邓克尔;后出版本的领起节)

- 表现:对待问题和议题时视角狭窄而非宽广(近义旧语"管窥蠡测");邓克尔称其为"思维贫乏的主要特征"。
- 成因:智力懒惰;学术门类在历史中不断增殖、各学科知识大爆炸→过度专门化,学者与自身学科外的洞断联。战争起因例:社会学家只看社会条件、经济学家只看经济条件、心理学家只看领导人内心动机,而有意义的答案通常是所有因素的结合;医生同类(内科开药/顺势疗法荐维生素/外科主张开刀)。
- 危害:眼光狭隘→思维贫乏;不只属于高专门化人群,每个人都危险。
- 解毒法:意识到自己经验的局限;训练思维扩展到熟悉事物之外;考察所有相关观点;判断前先理解。

### 1. 无根据的假定

- 定义:假定=仅仅认为理所当然而非经过理性思考提出来的看法。日常假定(手表会走、汽车会发动)无害且必要;越界即无根据:接受太多理所当然,超出自己的经验或具体情况所能证明的合理性(吸烟者、日光浴者、信网上股票信息者)。
- 常见实例(原文列举的十四条,逐条转述;危害各附一句):
  - 假定感觉总是值得信赖——信念和欲望会扭曲感知,使人选择性地看不看不。
  - 假定广泛报道的就是真的——虚构的故事也能像真理一样流传。
  - 假定有理由就等于逻辑推论过——理由可能是从他人处非批判借来的,借来的也可能不合逻辑。
  - 假定确信构成证据——人可能在情感上依附于一个错误。(呼应第八章)
  - 假定熟知的想法更有根据——熟知只说明听过读过,不保证正确。
  - 假定时间上在后即由前者引起——时间紧邻可能只是意外。(通向第十章事后归因)
  - 假定多数人的看法正确——多数人曾赞同处死女巫、容忍奴隶制。
  - 假定现在怎样就应当怎样——人与其发明都不完善,总有改进余地。
  - 假定变化总是变好——加税增岁入往往净效果相反("非故意的结果")。(通向反/支持变化偏见)
  - 假定表象值得信任——刘易斯看见乘客读自己的书正自豪,对方转手把书扔进海里。
  - 假定脑中的想法是自己的且值得护卫——不少想法是不加批判取自他人的,在任何重要意义上不是"自己的"。
  - 假定越确信越有效——有效性由证据的数量质量决定,与确信度无关;绝对确信仍可能错。
  - 假定发现论证有错即已反驳它——小缺陷不妨碍其余论据仍成立;反驳需要的不只是挑剔瑕疵。
  - (以上各条均"表现=一句口头禅,危害=把未经检验的东西当前提"。)
- 解毒法三步:①假定通常是暗示而非明说,像论证的隐蔽前提——养成领会字里行间未明说之意(读/听出言外)的习惯;②一旦识别,就评价它;③判断它是否超出你的经验或具体情况所能证明的合理范围。
- 政治案例示范:亲 choice 阵营流行的三假定(宪法规定了堕胎权/罗伊案判决逻辑无懈可击/只有保守基督教徒反堕胎)全属无根据——怀特大法官异议称其"行使粗鄙的司法权";反堕胎的还有门诺派、穆斯林、佛教徒、印度教徒、多个世俗团体。

### 2. 要么/要么观念

- 表现:期望任何议题唯一合理的观点要么完全肯定要么完全否定;连严肃书名都如此(《抢劫大王——海盗还是先驱?》《新政——革命还是改革?》《中世纪思维——信仰还是理性?》《历史是什么——事实还是想象?》)。
- 危害:否定了"很真实的可能性"——最合理观点也许是既/又、较少极端的立场;福利改革两极端可能都不对,最佳方案可能是"把它改得更好";教育补贴券可"同时肯定双方";男孩学业落后两嘉宾各自甩锅,实际可能两个原因都有还另有其他。
- 解毒法:每当你考察一个议题并发现自己只考虑两个选项,问自己是否还存在其他选项;如有,给予公平的倾听。

### 3. 盲目遵从

- 先划界(可取的遵从):安全与秩序的遵从(过马路先看两边、排队)、模仿好榜样的遵从——使生活更简单安全、助人成长。
- 表现:盲目遵从=不合理甚至不理智的遵从,动因是太懒惰或惧怕由自己思考;Asch 线段实验:7 名同盟给出明显错误答案,每 5 名不知情的真被试只有 1 人顶住压力答对。
- 渠道:广告商(百威"为什么要问为什么?试试百威干啤");各种群体——俱乐部、教堂、政党、兄弟会、工会,连标榜思想自由的群体也施压(嬉皮士不容异议;亨托夫同僚只在附和时才赞他捍卫言论自由);保守派亲枪支管制者、反积极行动计划的黑人作家同样受"与本群体保持一致"的压力。
- 危害:把"对"的标准外包给人群;多数与少数同时失守。
- 解毒法:对恳求、奚落、敦促一律抵制;自问什么是合理的、正确的,并遵循这条路线——无论你的立场属于多数人还是少数人。

### 4. 绝对主义

- 表现:相信必须存在规则而没有例外;期望真相清楚分明、确定、简单。
- 危害:对思考没耐心→过度简单化、草率结论;决心后即教条固执,拒收质疑证据;规则凌驾情境(忘带小刀的学生主动上交,反被停学并面临开除)。
- 解毒法:开始考察任何问题(哪怕思考过的)时,致力于接受你发现的事实,而不是要求它整洁简单。
- 界线:人人都会犯错、都可能不肯改口,绝对主义者只是更甚;且"相信绝对的东西"≠"绝对主义者"(如认为杀人总是不道德,但承认自卫可减免责任)。

### 5. 相对主义

- 表现:绝对主义的反面——用例外之多断言不可能有规则;相信真理是创造的而非发现的("你谈论的是谁的事实?我的也许与你的不同");一人信为真的对他即为真;道德纯主观("一个人认为可接受的,对他就可接受")。
- 危害:三重自毁——批判思考失去意义(其要旨正是区分真假合理不合理)、道德言说失去目的、法律失去正当性(若"选定即正当",反强奸反童恋反凶杀的法律反成对加害者权利的侵犯)。
- 解毒法(自洽测试):看该观点能否一贯地应用于日常生活——相对主义者既无法一贯地指责他人观点错误,也无法在抗议割礼、种族灭绝、奴役劳工、种族歧视时不否定自己的信条;不时提醒自己:有些思想和行为标准比其他的更好,批判性思考的挑战就是去发现最好的。

### 6. 支持或反对变化的偏见

- 标准答案先行:"你支持还是反对变化?唯一合理的答案是:'这取决于变化是什么?'"
- 支持变化的偏见:因生活在技术剧变时代、许多变化确实有益,错误推广为所有变化都好(比反对派常见于公开言论,但不如后者普遍)。
- 反对变化的偏见(更普遍),两大燃料:①熟知的力量——偏好知道且舒坦的思想(伽利略案:千百年日出日落"告诉"他们太阳在转,新思想威胁打包整齐的宇宙观并与宗教纠缠;自行车被医生说致"女色情狂";禁血汗工厂童工被斥共产主义阴谋;登月被斥"电视人的花招");②"我的更好"(第八章直连)——新旧习惯被视为唯一正确方式,新思想挑战安全感(弗罗斯特《修墙》之子修墙只因父亲这样做;帽子不上桌的外衣不上床:照做一生,没人问过"为什么",源头是邻家孩子的虱子)。
- 讽刺病灶:改革成功者迅速遗忘自己遭遇过的抵制,转而抵制后来者(弗洛伊德《梦的解析》8 年卖 600 本、受排挤;被接受后他与教条派反过来责难排斥霍妮)。
- 解毒法:检视你对新思想的第一反应,强烈赞同或强烈反对都不惊讶,但拒绝非批判地认可第一印象;悬置判断直到仔细考察;是真知灼见且证据充分就接受(无论古今),成问题就拒绝。

## 逐字摘录

- "立场的错误就像严重扭曲的镜片，除了不是戴在我们鼻子上，而是存在于我们头脑中这一点以外。"
- "视角匮乏是"思维贫乏的主要特征""（邓克尔）
- "除非你意识到自己经验的局限性，训练你的思维扩展到超越你所熟悉的事物，考察所有相关的观点，并在判断前先进行理解，那你就几乎可以肯定会眼光狭隘，其结果是思维贫乏。"
- "假定是仅仅认为理所当然而非经过理性思考提出来的看法。"
- "请记住，假定通常是暗示的而不是直接表达出来的，这很像论证中的隐蔽前提。为了识别它们，就要养成领会（或倾听）字里行间未明说却明显暗示了的想法的习惯。"
- "有可能在情感上依附于一个错误。"
- "一个想法的有效性是由支持它的证据的数量和质量决定的。我们确信的程度与此无关。"
- "反驳一个论证需要的不只是挑剔瑕疵。"
- "要么/要么观念的问题在于它否定了很真实的可能性，即最合理的观点也许是既/又——换句话说，是一个较少极端的观点。"
- "每当你考察一个议题，并发现自己只考虑两个选项，问问自己是否还存在其他的选项，如果有，就给予公平的倾听。"
- "与此相反，盲目遵从是不合理的，而且，在许多情况下是不理智的。这包括因为我们太懒惰或惧怕由自己思考而模仿他人。"
- "避免盲目遵从的秘密在于，无论他人为了让你像他们一样思考、讲话和行为而施加怎样的恳求、奚落和敦促，都要加以抵制。"
- "不要屈从，而是问问自己，什么是合理的、正确的，并遵循这条路线，无论你所处的立场是多数人的还是少数人的。"
- "绝对主义是这样一种信念，即必须存在规则而没有例外。"
- "绝对主义者期望关于议题的真相清楚分明、确定和简单。而在现实中，这样的真相却经常模棱两可、不那么确定，而且是复杂的。"
- "克服绝对主义的关键在于：当你开始考察任何问题（即使是你此前思考过的问题）时，致力于接受你所发现的事实，而不是要求它是整洁而简单的。"
- "相对主义的主要错误是相信真理是创造的而不是发现的。"
- "批判性思考的要旨就在区分真与假，合理与不合理；如果不存在假的、坏的或不合理的事情，那么，批判性思考就没有意义。"
- "对任何观点的简单测试就是看它能否自洽地应用于日常生活。"
- "你支持还是反对变化？唯一合理的答案是："这取决于变化是什么？""
- "我们的思维和行为习惯在我们看来是唯一正确的思维和行为方式。新思想挑战了我们的安全感，所以我们倾向于抵制它。"
- "拒绝非批判地认可你的第一印象，而是悬置你的判断，直到你仔细地考察了这个思想为止。"

## 辅导提示

- 用户说"这事只有两种可能,要么A要么B" → 要么/要么框架点破。引导:先原样复述他的二分,再命令式提问"第三个、第四个选项是什么?如果只能再加一个,它长什么样?"以福利改革句式改写他的议题:"最合理的观点也许是既/又"。(改编自本章应用练习3:找出"积极行动计划唯一选项是接受歧视""创世说与进化论之间必须选,中间立场不可能"里的错误并向没读过本章的人解释。)
- 用户说"大家都这么认为""十万个人转发还能有假" → 双重命中:无根据假定"多数人看法正确"+盲目遵从。引导:列举历史上多数人的错误(女巫、奴隶制),再问——如果只有五个人信,你还信吗?你信的理由有哪条不依赖人数?可讲 Asch 实验:每5人只有1人敢说出眼睛看得出的事实,你当时是哪一个?
- 用户说"我就是这么觉得""这还用验证吗" → 假定清单逐条对照(感觉可信/确信=证据/越确信越有效)。引导练习:(改编自应用练习1)拿一段他身边的对话(如"学校不会开学了,老师在罢工"式八卦),逐句挖出未明说的假定,标哪些有根据哪些没有。(改编)让 TA 复述一个自己坚信的观点,写出背后三条隐含假定,各自给出"经验或具体情况"层面的检验。
- 用户说"规矩就是规矩,没有例外"或反过来"哪有什么对错,都是相对的" → 绝对主义/相对主义对切。先问 TA 属哪边,再各下一城:对绝对主义者讲交小刀被停学的学生,问"你的规则遇上例外时会碎,还是世界会碎?";对相对主义者用自洽测试:"你抗议过不公平吗?那一刻你的'都对'还剩什么?"提醒中间地带:相信绝对准则≠绝对主义者。
- 用户说"新的一定比旧的好""老办法最靠谱" → 支持/反对变化偏见+"这取决于变化是什么"。引导:(改编自应用练习9)给 TA 一条真实改革提案(如"监狱图书馆撤走法律书籍"类),先记下第一反应是赞同还是反对、强度几分,再悬置判断重评一遍,对比两次结论;或讲帽子不上桌的故事,问"你现在照做的那条'规则',谁在什么时候为什么定的?"
- 用户说"我们是做产品的,这事本质就是产品问题" → 视角匮乏:战争起因的三学科比喻(你的单一镜头正在漏掉什么?)。引导:强制用经济、心理、制度三个镜头各写一段,再问"完整答案是不是它们的结合?"
- 用户说"我朋友没理我,他就是看不起我" → (与第十章草率结论共用)先按本章"发现其他可能性"处理:还有哪三种解释?
- 自我诊断作业(改编自应用练习7/8)——让 TA 回答:你更偏绝对主义还是相对主义?最可能在哪些领域(政治/宗教/社会问题/道德)犯?更偏欢迎变化还是抵制变化?分别在哪些领域?要求具体到议题。书的原话是"你越充分了解自己对待错误的特征倾向，就越能成功地克服它们。"
