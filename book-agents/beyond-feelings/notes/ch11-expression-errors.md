# 第十一章 表达的错误

定位:全书错误名录的第三类。前两章(第九章立场的错误、第十章程序的错误)管的是怎么想,本章管怎么说、怎么写——错误发生在向他人口头或书面表达看法的环节。它把批判性思考的自查时刻从思考中推进到输出时,给出六种(导言列七种,见提取异常)可逐条对照的输出端毛病与解毒法。

## 核心论点

### 0. 分类逻辑(先搞清单列一类的理由)
- 本章所有错误无一例外也是思维错误;分成四类的基本理由是:不同错误最明显地发生在思维全过程的不同阶段。
- 表达错误虽在心智早期就开始成形,但说和写的时候最容易指认和矫正——单列一类的作用是记住在何时需警觉它们:开口和下笔的瞬间。
- 全书坐标:第九章 = 解决任何问题之前就阻碍批判性思考的错误(立场);第十章 = 解决具体问题过程中的错误(程序);本章 = 表达看法时的错误;第十二章 = 遭到批评或质疑之后的错误(反应)。

### 错误名录(名称/表现/危害/解毒法)

**1. 自相矛盾**
- 表现:现在说一件事,尔后又反对它;在同一时间以同样的方式作出既真又假的陈述。典型形态:今天认罪明天翻供;相对主义者主张没有观点比别的更有价值,却斥责反对者;学者说物质世界虚幻,却因财产纠纷把邻居告上法院;电视大亨论证暴力节目不影响行为,转头赞扬靠公益公告改变行为的必要。
- 危害:违反矛盾律这一逻辑基本原则,论证体系从根上不可靠;公开场合被识破则信誉受损。
- 解毒法:①检查你所说的和所写的;②一旦察觉,仔细考察;③判定它是可解释的还是真矛盾——注意律条的限定条款:同一时间、同样方式(雇凶杀人是既谋杀了又没有谋杀,但不是以同样的方式:对行为负责 vs 亲自实施);④确认矛盾则重新审视问题,接受一个既自洽又合理的观点。

**2. 循环论证**
- 表现:以一种不同的形式重复一个陈述来证明它。简短版一眼看穿(离婚不断攀升因为越来越多婚姻破裂),加上考虑一系列因素之类的包装后,同一结构变得极难察觉。
- 危害:论证没有证据增量,貌似给出解释其实什么都没解释;关键不在于作者故意,而在于它会在我们未意识到时形成——所以自查不可省。
- 解毒法:仅重读并同意自己的观点不够;确凿查实支持观点的证据不只是用不同词语复述该观点。

**3. 无意义的陈述**(伴生形态:无意义的说明)
- 表现:声响大、实质空的陈述(广告语式);以及对无道理的理由做的说明——手工挑选汽车说明不了破产也给贷款,销售史无前例成功说明不了再延长十天。
- 危害:听者以为接收了信息,实际为零;是自我糊弄与糊弄受众的通用工具。
- 解毒法:像批判核查他人一样核查自己;逐条问自己是否确在做有意义的陈述;问给出的理由是否真正解释了它声称解释的事。

**4. 误用权威**
- 表现:把权威归属于并不拥有它的某人——问演收养欺诈剧的女演员角色是否让她对收养欺骗有深刻了解;更微妙的形态:某个领域的专家向他人介绍自己是另一领域的权威。
- 危害:名望光环冒充专业知识;这种错误发生的频度超出想象。
- 解毒法:确凿查实你作为权威引用的所有信息来源,拥有你所论**特定主题**上的专业知识。

**5. 错误类比**
- 表现:声称的相似性经不起仔细检验——想炒鸡蛋就得打破鸡蛋(为杀人正名);动物有四肢和肌肉会运动、地球没有所以不运动。类比本身合法:通过不同但比较熟悉的事物解释陌生的事物,只要宣称的相似性真实即可接受(例:癌症能致命但不能解释所有死亡,故历史罪恶不能解释此后所有罪恶)。
- 危害:借熟悉感实施误导,掩盖两事物之间的重要差异(人和鸡蛋很不相同)。
- 解毒法:随时核查类比所声称的相似之处是否真实、合理,是否存在重要差异。

**6. 非理性的诉求**
- 总机制:鼓励人们出于并无合理性的理由接受某些思想,等于叫人不批判地思考、不与别的想法比较,接受就是了。
- 六亚型(每型都有理性/非理性两面,**不可一刀切否定诉求本身**):
  - 对情感:理性 = 既激发感情又显示该感情的恰当性(酒驾事故现场配合反酒驾讯息;饥饿儿童面孔配每天80美分的说明);非理性 = 把情感当作思想的替代物(无证据指控对手预算抢儿童食物;律师煽情绕开证据;弑亲者请求法庭宽大因为自己是孤儿)。
  - 对传统:理性 = 展示传统仍值得我们认可;非理性 = 只因为我们一直这样做就坚持(人们最初反对牙刷、雨伞、飞机、电话、计算机;医生长期拒收病人洗手减少疾病传播的证据)。
  - 对适度:理性 = 解释为何适度想法比不适度选项更可取;非理性 = 建立在适度总是可取的错误假定上(奴隶制的适度方案是每人自决是否蓄奴,而奴隶没有发言权)。
  - 对权威:理性 = 说这是权威所说的,并着手表明为何应当接受;非理性 = 权威说了,不容置疑地接受。
  - 对共同信念:理性 = 说大多数人相信这一点,并表明该信念的合理性;非理性 = 因为大多数人都相信所以相信(常伴随每个人都知道它、理性的人都不会拒绝它、这是常识等说法;牺牲处女换好收成曾是常识,今视为胡说)。
  - 对宽容:理性 = 解释宽容为何在相关的特定情形中恰当;非理性 = 宽容普遍地好,所以对每种情形都正确(对恐怖主义、强奸、虐待儿童的容忍即怂恿)。
- **总判据(最可执行的一条)**:看这种诉求是否伴随着你为何应当接受它的解释。给了解释且证明合理 → 理性;没给解释或解释不可信 → 非理性。
- 危害:用情感、惯性、人数、名望、共识、姿态取代思考;看起来正确的想法有时不正确,不正确的想法可能产生有害结果。

## 逐字摘录

- "我们已考察了两类错误：在我们解决任何问题之前阻碍批判性思考的错误和发生在解决具体问题过程中的错误。在本章我们将考察第三类错误：在向其他人口头或书面表达我们看法时发生的错误。"(第十一章·表达的错误)
- "这些错误是：转移议题、自相矛盾、循环论证、无意义的陈述、误用权威、错误类比 和非理性诉求。"(第十一章·表达的错误)(注:转移议题在导言名录中,正文无专节)
- "采用四个类别的基本理由是，不同的错误往往（至少是最明显地）发生在所谓思维全过程的不同阶段。"(第十一章·表达的错误)
- "逻辑的基本原则之一是矛盾律，它表明不可能在同一时间以同样的方式作出既真又假的陈述 。"(第十一章·表达的错误)
- "矛盾究竟在什么时候发生？当某人现在说一件事，尔后又反对它的时候。"(第十一章·表达的错误)
- "为了克服自相矛盾，请检查你所说的和所写的。一旦察觉到任何自相矛盾，就仔细考察它。判定它是否是可解释的，或它是否构成了自相矛盾。如果证明它是矛盾的，就重新审视这个问题，并接受一个既自洽又合理的观点。"(第十一章·表达的错误)
- "进行循环论证的人试图以一种不同的形式来重复一个陈述来证明它。"(第十一章·表达的错误)
- "关键不在于作者故意构建循环论证，而是这种论证会在我们未意识到它时就形成。"(第十一章·表达的错误)
- "为了发现你写作中的循环论证，仅阅读并同意你自己的观点是不够的。你必须确凿地查实，你支持自己观点的证据不只是以不同的词语对该观点的陈述。"(第十一章·表达的错误)
- "为了发现你写作中无意义的陈述，像批判地核查他人所说的内容一样，核查你自己所说的东西。询问：我的确是在做有意义的陈述吗？"(第十一章·表达的错误)
- "误用权威的谬误把权威归属于并不拥有它的某人。"(第十一章·表达的错误)
- "这种错误的一种更微妙形式发生在某个领域的专家向他人介绍自己是另一领域的权威之时。这种错误发生的频度超出了你的想象。"(第十一章·表达的错误)
- "类比是通过参考不同但比较熟悉的 某事来解释比较陌生的某事的一种做法，实际上就是说：“这个与那个相像。”"(第十一章·表达的错误)
- "相反，一个错误的类比所声称的相似性经不 起仔细检验。"(第十一章·表达的错误)
- "随时核查你的类比，确保他们所声称的相似之处是真实和合理的，不存在重要的差异。"(第十一章·表达的错误)(注:他们 原文如此,疑为它们)
- "非理性的诉求鼓励人们出于一些并无合理性的理由而接受某些思想。"(第十一章·表达的错误)
- "最常见的非理性诉求的种类有：对情感、传统、适度、权威、共同信念 和宽容 的诉求。"(第十一章·表达的错误)
- "相反，对情感的非理性 诉求是把情感当作思想的替代物 。"(第十一章·表达的错误)
- "人们最初反对牙刷、雨伞、飞机、电话、计算机和几乎每一件其他的发明，因为“我们的祖先没有这些新奇玩意也过得很好”。"(第十一章·表达的错误)
- "适度的看法会是让每个人决定他或她是否拥有奴隶。（当然，奴隶在此决定中不会有发言权。）今天，没有一个负责任的人会赞同这种观点。"(第十一章·表达的错误)
- "由于权威也不能特别地免除错误，从不质疑他们所宣称的东西的想法就是愚蠢的，因而也是不能接受的。"(第十一章·表达的错误)
- "这样的非理性诉求经常伴随这样一些说法：“每个人都知道它”，“理性的人都不会拒绝它”，或者“这是常识”。"(第十一章·表达的错误)
- "许多或大多数人相信某件事的事实并不是让我们相信它的充足理由。"(第十一章·表达的错误)
- "容忍这些行为的社会会怂恿它们，并犯下进一步侵害这些受害人的罪行。"(第十一章·表达的错误)
- "区别理性和非理性诉求的最好办法就是看这种诉求是否伴随着你为何应当接受它 的解释。如果提供了一个解释，并证明它是合理的，那么这个诉求就是理性的。如果没有提供解释或所提供的解释不可信，那么这个诉求就是非理性的。"(第十一章·表达的错误)

## 辅导提示

(向导姿态:先照出用户话里的隐含假设与思维毛病,不急着给答案,再引导用户自己把论点重答一遍。)

- 用户声称自己的观点绝无矛盾、别人误会了他 → **自相矛盾**框架:先不辩对错,请用户把并行持有的几个主张逐条写下、两两对照,特别对照主张与行为(电视大亨式结构:一边说节目不影响行为,一边指望公益广告改变行为);再问:这是可解释的(不同时间、不同意义)还是真矛盾?
- 用户的论证里,论据只是结论的同义改写 → 点破**循环论证**:把支持句与结论句并排,问删掉换词复述之后还剩多少证据;没有增量就重写论据部分。
- 用户拿一段自认很有气势的文案或提案来求评价 → **无意义的陈述**检验:逐句删掉形容词与口号,看剩下多少可验证的内容;再问给出的理由是否真正解释了要解释的事(二手车商给贷款找理由的结构)。
- 用户搬出某位大佬、名人或跨界专家的言论作为依据 → **误用权威**:一个问题照回去——这个人在当前这个特定主题上有专业知识,还是只在别处有名?
- 用户用比喻说理并咬定两者就是一回事 → **错误类比**解毒:请用户列出被比事物之间的三条重要差异;列不出,类比可疑;轻松列得出,类比只剩修辞价值,论证仍需补实质证据。
- 用户冒出这几类话头——一直这么做、大家都这么认为、取中总不会错、权威就这么说的、这是常识、该宽容就宽容 → 按六类**非理性的诉求**逐一对号,然后统一用总判据引导:请补一句为什么应当接受它;给不出解释,或解释不可信,该主张就需重新论证。
- 关键提醒(防一刀切):本章不是禁用情感、传统、适度、权威、共识、宽容,而是分清理性与非理性的诉求——附带恰当解释的诉求是允许的,批判的思考要求区分二者。
- 思考练习(可抛回给用户):

  - 选一个你现在坚信的观点,把观点句和支持理由各写一遍,对照:理由是独立证据,还是观点换个说法?再对照你的其他主张,找有没有今天承认、明天否认的配对。(改编自本章应用练习)
