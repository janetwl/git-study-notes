# 第十三章 错误组合

定位:全书错误名录的总复盘章,不新增错误。它干三件事:①把第九至十二章的所有错误压缩成一份可按阶段翻查的辨识-解决清单;②用三个案例示范错误如何成链发生,教读者从表面行为倒推出错误链条;③给出一张术语辨析表,解决最容易混淆的三个错误怎么分。这一章是从逐条学错误走向综合用错误的那一步。

## 核心论点

### 0. 为什么必须讲组合
- 错误既可单独出现,更常组合出现。示例链:我的更好思维 → 造成反对变化的偏见 → 带有偏见地选择证据 → 草率的结论。
- 组合的共性:多种错误共同发生时,它们对批判的思考形成的障碍比任何一个单独错误都要大。
- 万恶总根:我的更好——假定自己的想法一定优于他人,仅仅因为那是自己的想法;矫正:像对待他人的想法一样批判地对待自己的想法。

### 1. 四类错误总清单(名称 + 一句话辨识 + 一句话解毒;全名录)

**立场的错误(形成观点时,承第九章)**
- 视角匮乏:限制一个人看议题的视角、管窥蠡测;源于智力懒惰或专业化训练的副产品 → 超越自己熟悉的观点,考察所有相关观点,在做判断之前先理解。
- 无根据的假定:被当作理所当然而非有意识推理出来的想法;当某人的经验或境况否定了被当作理所当然的事时无根据;很少直接说出 → 唯一办法是从字里行间读出未说出但明显暗示的事情。
- 要么/要么观念:期望唯一合理观点要么完全肯定要么完全否定,排除了最合理看法位于两极之间的可能 → 考虑所有可能的选项。
- 盲目遵从:轻率采纳他人观点,因为太懒惰或害怕形成自己的观点 → 养成抵制内部和外部压力的习惯,用自己的头脑作决定。
- 绝对主义:相信规则不承认例外,要求真理整洁简单 → 按你发现真理的原样接受它,不要求它适合你的先入之见。
- 相对主义:认为没有一个观点比其他更好、你选的肯定对 → 提醒自己有些思想、有些行为标准比其他的更好,批判性思考的挑战就是找到最好的。
- 支持或反对变化的偏见:假定改变总是趋向最好/总是趋向最坏 → 公正地倾听任何一个改变的建议,抛开自己的立场判定改变确实正面还是负面。

**程序的错误(解决问题过程中,承第十章)**
- 有偏见的证据考量:两种形态——寻找肯定偏见的证据并忽视质疑它的证据;以支持偏见的方式解释证据 → 让研究始于找出反对你偏见的那些人的观点,再找支持它的;并选择对证据最合理的解释。
- 双重标准:用一套标准判断我们赞同的论证、另一套标准判断我们不同意的论证 → 提前决定使用什么标准,并前后一致地运用,无论材料是否支持你的观点。
- 草率的结论:不成熟的判断,没有充分证据 → 在选择任何一个结论之前先辨认出所有可能的结论,再判定有无充分证据支持其中哪一个。
- 过度概括和刻板成见:把仅适合群体某些成员的东西归属于所有成员;刻板成见是僵化地坚持过度概括 → 抵制把个人、地点和事物强行归入硬性类别的冲动;经验越有限,断言越要谦逊。
- 过度简单化:超出让复杂思想易于理解的范围,歪曲或扭曲思想,不是告知而是误导 → 拒绝肤浅的观点,特别努力去理解问题的复杂性。
- 事后归因谬误:认为一事件发生在另一事件之后必定是其结果,而衔接可能是巧合 → 暂缓因果判断,直到排除其他可能的原因,包括巧合。

**表达的错误(输出时,承第十一章)**
- 自相矛盾:声称一个陈述在同一时间以同样方式既真又假 → 核查所说所写;发现不一致时判断可解释还是真矛盾;确认矛盾就纠正陈述使之自洽合理。
- 循环论证:以不同形式重复一个陈述来证明之 → 检查论证,确保提供的是真正的证据,而不只是重复主张。
- 无意义的陈述:所表述的推理没有什么意义的陈述 → 确凿查实你提供来解释自己思想和行为的理由真正解释了它们。
- 误用权威:把权威归属于并不拥有它的某人 → 查实所有被引为权威的信息源拥有你所写或所说特定主题上的专业知识。
- 错误类比:类比声称的相似性经不起仔细检验 → 检验类比,确保相似性真实合理、不存在重要的差别。
- 非理性的诉求:对情感、传统、适度、权威、共同信仰和宽容的诉求可以是理性的或非理性的;在所讨论的特定情形中不合理和/或妨碍思考时即非理性 → 确保你的诉求是对思考的补充而不是取代思考。

**反应的错误(遭批评时,承第十二章)**
- 自动拒绝:不愿意公正地倾听对你的思想或行为的批评 → 把你的思想视为可保留或抛弃的所有物,而不是自我的延伸。
- 转移话题:突然并欺骗性地把讨论从正在谈论的议题转移开 → 迎头面对困难的问题,而不是试图避免之。
- 转移举证责任:要求其他人否证你的命题 → 明白支持断言的责任在于作出断言的人而非质疑者,承担起支持你断言的责任。
- 稻草人:把不实之词强加于别人身上然后揭露其虚妄,适时地忘了此人从来没说过这种话 → 在引用和解说他人的话时严格地准确。
- 攻击批评者:通过贬损表达某个想法或论点的人来诋毁这种想法或论点 → 把批判性思考集中于想法而不是表达想法的人。

### 2. 组合诊断五步法(本章的方法论核心,从三个案例逆向提炼)
1. **定阶段**:错误发生在哪个环节——形成观点(立场)、求证(程序)、输出(表达)、被批(反应)?按上面清单逐类扫描。
2. **找第一错误(总根)**:多数链条的起点是我的更好、盲目遵从或无根据的假定。克劳德案起点是党派认同的我的更好;萨姆案起点是同伴遵从;史蒂芬案起点是假定斯坦先生是犹太人。
3. **顺链条**:第一错误如何喂养后续错误。克劳德:我的更好 → 高估所认同的、低估所不赞同的 → 表达时过度简单化 → 被质疑时转入围保全面子的手法(指责对方歪曲其话、否认自己说过的、无视反例事实)。史蒂芬:无根据假定 → 刻板成见(犹太人照顾自己人)→ 拒绝成绩的合理解释、自我安慰(老师只是吓唬我)→ 挂科后攻击批评者(宣称老师是骗子)保全面子。
4. **数面子的量**:一个人越深刻地投入一种思想,就越不大可能承认它的错误,从中学到的也越少——投入度是链条粘合力,诊断时先估用户对该观点的身份投入。
5. **不执着于命名**:能认出推理在哪里出错、能根据所涉及的问题解释错误,比叫出正确术语更重要;大多数情况下简洁的语言够用。

### 3. 高频三岔辨析:过度简单化 vs 草率结论 vs 无根据的假定(本章给出的正式区分表,大意)
- 是否说出口:前两者直接陈述出来;假定是未陈述但暗示的。
- 在论证中的角色:过度简单化作为简单断言或论证的前提出现;草率结论作为论证的结论出现;假定经常是论证的隐蔽前提。
- 错误方式/检验法:过度简单化通过错误陈述或遗漏歪曲现实;草率结论不能说明一个或多个重要的证据项;假定则要看它有无根据(是否被证据支持)。
- 注:三者混淆是思维错误归类中最常见的错误来源,本章专门列表消除。

## 辅导提示

(向导姿态:用户的思维毛病很少单发,本章是给向导用的全套会诊流程——先让用户讲一个具体的失败争论,再按五步法定位。)

- 用户说:我道理都懂,可每次争论还是一团糟/我朋友不可理喻 → 组合诊断入口:不修单个错误,请用户完整复述最近一次失败争论,按五步走——定阶段、找第一错误、顺链条、数投入、别急着命名。多数一团糟背后是两三个错误的流水线。
- 用户明显站队极深(粉圈、党争、站队式消费品牌)并问对方为什么这么傻 → 克劳德模板:我的更好 → 高估自己认同的一方、低估反对的一方 → 输出时过度简单化 → 被提醒时启动保全面子手法。引导用户做内尔做的事:自己平静列出己方两三个真实缺点和对方两三个真实优点,再重答一次原问题。
- 用户为习惯辩护(抽烟/熬夜/拖延)并说这事每个人自己判断 → 萨姆模板:先找起点(遵从同伴),再抓要么/要么(要么偷钱要么没烟抽)、面子归因(呼吸困难怪过敏)、转移举证责任(他们未能证明吸烟导致任何疾病)、无根据假定(富高管没理由做坏事)。让用户逐环重答:哪一环愿意补上独立证据?
- 用户把失败归因于评委/老师/领导不公 → 史蒂芬模板:先查自己最初的无根据假定与刻板成见(对方属于我的群体就会照顾我),再看是否拒绝了最合理的解释,最后查挂科后的攻击批评者。引导:先列出对方第一节课就说过的规则原话,再回答成绩是否有更平淡的解释。
- 用户问这到底算过度简单化还是草率结论还是隐含假定 → 给三岔辨析三问:说出口了吗?它在论证里当什么角色(前提/结论/隐蔽前提)?要推翻它需要看什么(歪曲或遗漏了现实?漏了哪个重要证据项?假定有没有证据支持?)。同时提醒术语纪律:叫不出名字没关系,说清推理在哪里出错才算真懂。
- 用户轻信权威表演(某大V演讲很高深) → 用本章应用练习的福克斯实验讲机制:无意义、自相矛盾的内容配上唬人头衔与行话,55 名教育者无一人识破;请用户把内容的实质性(可检验的陈述)与包装(头衔、掌声、术语)分开,各自重评一次。
- 用户只要一个非 A 即 B 的答案,且规则不容例外 → 点名要么/要么 + 绝对主义这对常见组合;解毒分别是考虑所有可能的选项、按真理发现的原样接受它(真理经常杂乱而复杂)。
