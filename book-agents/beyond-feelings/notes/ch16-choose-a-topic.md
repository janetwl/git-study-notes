# 第十六章 选择一个议题

定位:第三篇"策略"的选题环节——按部就班流程的第一步实战:在展开观察、研究、论证之前,先把"要思考什么"定准。本章解决"议题过大导致思考必然肤浅"的问题,给出"少是多"原则和限定议题的完整操作步骤,其产物(聚焦问题)是后面几章研究与论证的作业对象。

## 核心论点

### 议题的定义与为什么必须谨慎选题
- 议题:批判性思考语境中,指人们对其易产生分歧的任何问题;几乎就是"争论"的同义语(本章脚注:"有争议的议题"这种表述虽然常用,却是累赘的)。
- 议题不限于道德、法律、政治(堕胎是否谋杀、少年重罪是否成人受审、"软"钱是否腐蚀竞选),也遍布农业、投资、学术、执法各领域——分歧存在于一切领域。
- 常见毛病:这类发言太常见太自然,以至人们回答得太随意;认为对自己看法"享有权利"的信念,让人壮胆表达并不持有证据的观点。批判的思考者则把谨慎选题当作思维过程的重要部分。

### 基本原则:少是多(为什么宽题目必败)
- 错误动因:对空白页面的恐惧→怕题目太小"没到字数就说完了"→故意选大题目(体育、疾病、战争)求保险。
- 驳斥:这种安全感完全是想象的;500 字甚至几千字也装不下一个宽议题——"就像尝试把一加仑水倒进一品脱（=1/8加仑）的容器里一样徒劳无功";写介绍性文章也救不了。
- 对手并不天真:判断你分析的读者多数既知道议题的复杂性,又可能有五六条反对你的理由→肤浅的、从头到尾马马虎虎的处理肯定会失败。
- 唯一明智解法:限定分析范围——议题有五个或十个重要方面,就只考察其中一个或两个,腾出篇幅解决复杂性、作出重要区分、处理细节。"少是多"=目的在于深度而不是广度。

### 如何限定一个议题(三步法)
1. 尽你所能列出议题的多个方面——重要且激烈争论的议题,清单可能有十几个方面。
2. 准确判定你将解决哪些方面——很少能恰当处理所有方面;选定标准=你的兴趣 + 分析的时机和目的 + 可利用的时间和篇幅。
3. 用一个或更多清晰的、仔细聚焦的问题来探查你所关注的方面——把问题**写下来**;它让随后的研究集中于主题、防止偏离;当思想转向某方向时,迅速对照这些问题判断该方向是否可能出成果。

### 样本题(本章用 3 个议题示范"方面"拆解)
- 色情文艺(核心问题:色情文艺是有害的吗?):受众 / 主题 / 商业安排 / 演员 / 声称的有害影响 / 在性传播疾病中的作用 / 言论自由——共 7 个方面,每个方面配一组聚焦问题。
- 拳击(核心问题:应宣布拳击为非法吗?):拳击手谋生的权利 / 拳击与精神健康 / 拳击的大众性(受欢迎能否成为允许的理由)/ 把拳击划归为体育是否恰当 / 能否通过改规则降低危险 / 挨拳击的(积累)后果——共 6 个方面。
- 青少年犯罪(核心问题:应当像对待成年罪犯一样对待青少年罪犯吗?):原因(唯有少年负责吗)/ 承担责任的年龄 / 青少年与成年人之异同 / 公布事实的影响 / 监禁的影响 / 犯罪的差别(轻罪重罪是否区别对待)/ 惯犯与初犯 / 监狱(是否关进成人监狱)——共 8 个方面。

### 进一步收拢议题(方面还是太大时)
- 判据:单个方面仍宽泛到不能在可控的时间和篇幅内恰当处理。
- 做法:找一个**能被分成几个部分**的方面,集中关注其中一部分(并非所有方面都可分,但大多数情况下能找到可分的)。
- 例 1(主题方面→只考一种性活动种类×单一媒体/一种杂志:仅考察在单一媒体和杂志上对成年人之间强迫性行为的关注)。
- 例 2(声称的有害影响方面→四个问题聚焦其一;选"态度"问题则再集中于爱情、婚姻、责任之一)。
- 限定范围的四重收获:①更明确的关注重点;②提升保持在能力范围之内的机会、使分析更容易掌控(争夺注意力的话题越少,分心或困惑的危险越小);③即使能处理多个子议题,仔细确认所有子议题也使研究更有秩序、更有目标;④减少把复杂问题过度简单化的可能性(直接呼应第二篇"过度简单化"错误)。

### 应用练习(本章 3 项)
1. 对给定议题运用本章方法(联邦所得税改革、小学性教育课、收紧离婚法、神志正常者能否自杀、学生注意力范围是否缩小、卖淫合法化、游说非法化、禁儿童节目广告、恶魔崇拜是否威胁社会、UFO 外星物信仰是否合理、男运动员是否比女运动员优越、"政治的正确性")——确保选自己感兴趣的,因为后面几章的应用以此为基础。
2. 把本章方法用于前几章练习中出现过的议题(写作课必修、高中教创世说、一夫多妻制合法化、投票年龄降至 16 岁、三 K 党集会自由、惩罚 vs 改过自新、大学学位的就业意义、给未成年人开避孕处方是否须通知父母),并忽视先前的分析重来。
3. 从最近的国际、国内或本地新闻中选一个议题,以问题形式陈述它,再运用本章方法。

- "如果你遵循上面的方法，并发现即使这些单个的方面也太宽泛了，以至不能在你控制的时间和篇幅内恰当地进行处理，那就寻找这样一个方面，它能被分成几个部分，并可集中关注其中的一部分。"
- "限制你处理的一种方式可以是仅考察在单一媒体和杂志上对成年人之间强迫性行为的关注。或者你可能通过集中关注一种杂志而进一步限制你的处理范围。"

## 辅导提示

- 用户抛出一个巨型问题("教育体制到底烂不烂?""这个行业还有没有前途?")→ 隐含假设:问题可以按原样回答。先照出"一加仑水倒进一品脱容器"这一结构,再用三步法陪他跑一遍:列方面→挑一个(兴趣×时机目的×时间篇幅)→改写成写下来的聚焦问题。
- 用户的文章/方案被批"太浅、大而全"→ 用"读者可能有五六条反对你的理由"论证:浅不是笔力问题,是选题超载;引导他砍到一两个方面,腾出的篇幅用来"解决复杂性、作出重要区分、处理细节"。
- 用户说"我只讲一个方面,会不会显得考虑不全?"→ 照出隐含假设"全面=每个方面都碰一句";引"少是多":广度上的敷衍必败,深度上处理一个方面反而更能应对反对者。
- 用户选定方面后仍觉得写不动→ "进一步收拢"技术:找一个能分部分的方面,聚焦其中一部分(参照例 1、例 2 的两次收窄)。
- 用户说"这是我个人的看法,我有权这么想"→ 本章开篇照出:"享有权利"的信念如何让许多人壮胆表达并不持有证据的观点;权利问题不是真伪问题,选题谨慎才是思维过程的一部分。
- 用户想同时讨论多个子议题、思绪乱飞→ "争夺你注意力的话题越少,变得分心或困惑的危险就越小";让他把所有子议题仔细确认写下来,研究才有秩序和目标。
- 思考练习(改编自本章应用练习 3):让用户从本周新闻挑一个议题,先改写成"……吗?"式问题陈述,列出至少 5 个方面,选出 1 个并写成聚焦问题——声明"后续思考将以此为基础"。
- 思考练习(改编自本章应用练习 2):取用户过去与人争过的一个老议题,用本章方法重来一遍,并刻意"忽视你先前对该问题的分析"。
