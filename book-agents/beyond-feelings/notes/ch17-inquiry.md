# 第十七章 进行探究

定位:第三篇"策略"部分的操作手册开篇。第十六章教你确定和阐述议题,本章解决接下来的问题——议题定下之后,到哪里找材料、找多少才算够、面对长篇文献如何把论证拆出来,即"探究"的具体操作步骤。

## 核心论点

**1. 探究的定义与两分**
- 探究 = 寻求问题的答案、研究问题和收集信息,以帮助得出结论;作用是超越第一印象、第一感觉、先入之见和个人偏好。
- 两种基本探究:探究事实、探究观点。观点分有见识与无见识,除非目的要求兼收,应更关注有见识的观点。
- 多数真实议题需要两者混合。书中税务例子:考察税法条文(事实)+ 请教税务专家解读(有见识观点)+ 生活费用统计(事实)+ 请教经济学家(有见识观点)。

**2. 处理不确定的结果**
- 人类知识现状不完善,有些议题几个世纪都无定论(失重对宇航员的影响、摩西所爬的山的地点、外星智能生命)。
- 探究即使只产生不可检验的专家意见,也比无见识的随意推测有价值;对答案能达到的"彻底性和终极性"持现实态度,但不被困难议题吓倒。

**3. 到何处寻找信息(来源清单,按顺序)**
- 首先考虑自己的经验和观察——但要对其与议题的相关性保持敏感,且它本身通常不足以处理复杂争议问题。
- 问题的背景:综合性百科全书(《美国百科全书》《大英百科全书》,先查索引卷)→ 专业百科全书(艺术、商业、历史、哲学等)。注意:背景阅读只是开始,不是分析的替代品。
- 事实和统计资料:各类年鉴(《世界年鉴》《读者文摘年鉴》等),使用前先学会用索引。
- 关于人:传记词典(《当代传记》《韦氏传记词典》)。
- 关于语言:《牛津英语词典》、同义词词典、俚语词典。
- 报刊杂志文章:《读者期刊文献指南》+ 各学科索引(社会科学索引、人文学科索引、纽约时报索引等约20种,可按领域选用)。
- 书籍:图书馆书目卡片或电脑目录;检索困难时请图书管理员帮忙(他们是受过专业训练的检索人员)。
- 电脑数据库与摘要检索服务:infoTrak、《综合学术索引》、Lexis-Nexis、Westlaw、PsycINFO、PubMed 等;能否使用取决于本校馆藏,仍以图书管理员为第一咨询人。
- 因特网(见下)。

**4. 因特网查询的三步策略**
- 步骤1 使用搜索引擎:搜索词越宽泛结果越多("教育"约6000万条 →"美国教育"约600万 →"美国教育的体罚"低于5万),所以准确选择搜索词并必要时修改;先熟悉引擎各功能入口;善用"类似网页"缩小搜索;看到有用页面先复制网址再关闭。可用元搜索引擎。
- 步骤2 开发资源清单:按主题(争议观点、历史、法律、医学、恶作剧核查等)积累常备网址,发现有用的就加入清单。
- 步骤3 评价信息来源:不能假定来源无差错;记者会犯非故意过错,评论者有偏见,私人目的者会故意误导;网络尤其危险——没有编辑检查,任何人都能建网站畅所欲言。看域名后缀判断站点性质(.gov 政府/.edu 教育/.com 商业),网站反映创建人的倾向和/或议程。对转发的"电子邮件震惊体"要警惕(比尔·盖茨捐款、含食肉细菌的香蕉、删"玩具熊图标文件"等均为恶作剧)。

**5. 集中于焦点**
- 探究不等于苦役:翻到书末索引查几个标题,只读被引的页码;无索引则看目录挑章浏览。
- 因特网分心物更多,需特别努力约束搜索、聚焦相关材料。

**6. 多少探究才够充分(与第六章呼应)**
- 复述第六章判定证据充分的三档标准:
  1. 能作出确定性判断时(没有站住脚的理由去怀疑、无争执基础;刑案标准"超出合理怀疑");
  2. 达不到确定性时,一方观点显示出很大可能性(民案标准"证据优势";论证合理性 ≠ 单纯主张合理性,且须先找出并评估所有可能观点);
  3. 其余情况证据即不充分——唯一审慎的行动是暂缓判断,直到获得充分证据;克制是批判性思考者的重要特征。
- 探究量没有绝对答案,完全取决于议题;当你全面了解相关事实、并考虑了对该议题有直接影响的所有领域里有见识的观点,即可合理确信探究充分。
- 操作方法:为议题列出"有直接影响的领域"清单(例:色情文艺的影响→社会学/心理学/文学批评/伦理/宗教;挨拳击的后果→解剖学与生理学/医学/心理学;承担责任的年龄→教育/心理学/医学/伦理/法律)。
- 最大挑战之一:遇到第一位支持你偏见的 knowledgeable 之士就想停止探究——按定义,议题就是有见识、谨慎的思考者可能反对的事情。
- 告诫:考察议题两方面 ≠ 两方面优点同等;但"每一方都有足够优点使判断困难"也绝不能证明避免判断是合理的。

**7. 处理长篇材料:整合论证的六步**
长文中前提可能分散在第2页、第5页,结论在第12页,评价前须先整合论证:
1. 读完后回头确定关键断言(主题句;小标题、大写/黑体/斜体标示;加强词"而且、的确、更(最)重要");
2. 找出作者的结论(文章:导言后/结尾;书:首章/末章;"由于这些原因、因而、所以、因此"标示结论);
3. 注意关键断言中的修饰词(所有/大多数/某些;总是/通常/偶尔/从不;注意"但是、然而、另一方面"引导的平衡句);
4. 注意支持断言的证据的数量、种类和来源(回查第六章);
5. 注意作者包括的条件("如果、除非、只要、直到、在……之前"可大大改变断言含义);
6. 写一篇准确总结(一两段即可,是原作的摘要版本,不许把"也许是"写成"它是")。
- 本书给出一个"建议取消成绩"文章的一段式样本总结(此总结在第十八章被逐句提问分析——跨章衔接点)。

**8. 应用练习(可用作辅导任务)**
- 练习1/2:选第十六章确定并阐述过的议题(或卖淫/拳击/青少年犯罪议题),按本章方法探究并仔细记录。
- 练习3:选一个正在辩论的校园/社区/国家议题,a. 在 google 做一般搜索和"新闻"搜索;b. 访问观点栏网站,赞同方至少读两栏、反对方至少读两栏;c. 详细记录发现。

## 逐字摘录

- "探究是寻求问题的答案、研究问题和收集信息，以帮助我们得出结论。它使我们超越第一印象、第一感觉、先入之见和个人偏好。"(第17章·进行探究)
- "有两种基本的探究：探究事实和探究观点。请记住，观点可以是有见识的，也可以是无见识的。除非我们探究的目的要求收集这两类观点，我们应该更关注有见识的 观点。"(第17章·进行探究)
- "当然，无论一个问题如何与解决方案相抵触，但探究还是有益的。即使它只是产生不可检验的 专家意见，这些意见也比无见识的随意推测要有价值。"(第17章·进行探究)
- "对我们的经验与正在考察的问题之间的相关性保持敏感，不仅能给我们宝贵的意见，而且也能提出重要的问题。因此，它能为我们的探究提供较好的方向。"(第17章·进行探究)
- "你在找到文章并阅读之后，务请检查下一期致编者信函栏目的读者回应。"(第17章·进行探究)
- "搜索词越宽泛，你得到的信息就越多。“教育”可能产生6000万条信息；“美国教育”可能是600万条；“美国教育的体罚”，低于5万条。"(第17章·进行探究)
- "网站反映其创建人的倾向和/或议程。"(第17章·进行探究)
- "不应假定信息来源都是无差错的。平面媒体和广播电台的记者在报道中也可能犯非故意的过错。评论者也可能让偏见影响自己的思想和表达。怀有私人目的的个人可能故意误导他们的听众。"(第17章·进行探究)
- "一个洞见可以造成很大的差别。一个新事实可能颠覆一大堆证据。"(第17章·进行探究)
- "1．当可以作出一个确定性的判断时，证据就是充分的。 希望、假定或假装一个判断是正确的，并不构成确定性。当没有站住脚的理由去怀疑、也没有争执的基础时，就存在确定性。"(第17章·进行探究)
- "3．在其他所有情况下，必须认为证据是不充分的。 也就是说，如果证据并未显示出某个观点比竞争的观点更合理，那唯一审慎的行动方案就是暂缓作判断，直到可以获得充分的证据为止。这样的克制可能是困难的，特别是当你要证明某个特定的观点具有优势的时候，但是，克制是批判性思考者的重要特征。"(第17章·进行探究)
- "多少探究才够充分？不存在简单易行的答案。它完全取决于议题。在某些情况下，简单的探究就足够了。在其他情况下，竭尽全力的探究也是不完全的。"(第17章·进行探究)
- "对批判性思考的最大挑战之一就是当你发现一位知识渊博之士支持你的偏见时，让你停止探究的那种诱惑。当这个人是你遇到的第一个人时，这种诱惑将特别地强烈。"(第17章·进行探究)
- "这里提出一个告诫是合适的：说考察一个议题的两个方面是重要的，这并不 意味着两个方面都具有同等的优点。往往会有这样的情况，即每一方都有足够的优点会使得判断变得困难，但这决不能证明避免判断的合理性。"(第17章·进行探究)
- "在你能评价这些情形中的论证之前，你需要把论证进行整合。"(第17章·进行探究)
- "(这里不可为引用和解释原作时的粗心大意留下余地：如果它说某事也许是 某种方式，那就不是说它是 那种方式；类似地，是 并不必然意味着应当是 。)"(第17章·进行探究)

## 辅导提示

- 用户说"我已经查了很多资料,心里有数了" → 先照出隐含假设:他查的是"事实"还是只是"支持性的观点"?用本章两分(探究事实/探究观点,且观点分有见识/无见识)让他给手头的每条材料贴标签,再问他缺哪一类。
- 用户问"到底查到什么程度才算够" → 不直接给答案,让他用本章复述的第六章三档标准自评:你的证据到"确定性"了吗?到"很大的可能性/证据优势"了吗?还是两个都没到、按定义就该暂缓判断?引导他自己说出属于哪一档。
- 用户找到一个专家/大V支持他的观点并就此打住 → 直接引用本章"最大挑战"警告:第一位支持你偏见的行家恰恰是停止探究诱惑最强的时刻;问他:这位专家是你就议题遇到的第一个人吗?还有哪几个“有直接影响的领域”没查?让他仿照色情文艺/拳击/责任年龄的例子列出自己议题的领域清单。
- 用户说"两边都有道理,所以没法判断" → 用本章告诫对撞他的假设:"考察两方面"不等于"两方面同等优点",而"判断困难"也"决不能证明避免判断的合理性";引导他进入第十八章的评价程序。
- 用户被网上信息绕晕/担心被带节奏 → 走本章因特网三步策略,重点练第3步:看域名后缀、问"网站反映创建人的什么倾向和/或议程"、这条消息是否属于"邮件恶作剧"体质。
- 用户面对一本厚书/长论文发怵 → 教"集中于焦点"(只读索引所引页码)+ 整合论证六步;练习:挑一篇10页以上的立场文章,用六步压成一段准确总结,检查有没有把"也许是"抄成"它是"(改编自本章"处理长篇材料"第6步)。
- 用户议题刚定(接第十六章)不知从哪下手 → 按本章来源顺序给路线图:自己的经验→百科全书找背景→年鉴找事实→索引找文章→数据库/网络补充;并提醒背景阅读"决不是分析的一个可接受的替代品"。
- 实操练习:选一个你所在城市/学校正在辩论的议题,做一般搜索和新闻搜索各一次,再找"赞同"与"反对"两栏评论各至少两篇,列出每篇背后的信息来源类型,标出哪些是有见识的观点(改编自本章应用练习3)。
