# 第十八章 形成判断

定位:探究的终点站,全书策略部分的收束章。它回答:材料齐了之后,判断如何从证据和推理中审慎地产生、检验并说出来——评价证据、评价他人论证、作出六种关键区分、用六条指南表达判断,最后把第14–18章的方法压缩成五步总清单。

## 核心论点

**1. 判断是什么**
- 判断是通过证据考察和仔细推理得出的结论,是思考的结果;不同于感觉,不是自发和无意识的。直觉等因素可以进入判断,但必须先经过权衡和评价。
- 判断不保证有价值:有愚蠢的也有明智的、有肤浅的也有深刻的;它可能包含第8–13章讲过的任何一种思维错误。
- "程序越是科学就越不需要评价"是流行而错误的看法:科学事实仍须被分类、解释为有意义(中国古墓2100年前女尸例:大量化学分析与X光事实,只有经解释才能得出"她生过孩子、死前吃过甜瓜、可能死于冠状动脉堵塞")。信息越零碎、观点冲突越激烈的领域,判断质量越依赖评价。

**2. 评价证据 = 提出并回答恰当的问题(与第六章的11种证据呼应)**
对每种证据问其专属问题(大意,逐字问题见原文表):
- 个人经验:典型吗?数量与种类充分吗?
- 未公布的传说:源头何处?如何证实你听到的版本准确?
- 公布的报道:引用了重要信息来源吗?作者/出版者有认真报道的声誉吗?哪些陈述会被慎思者质疑?
- 目击者证词:哪些情境扭曲了感知?哪些情境影响回忆?
- 名人证言:是否收费发言人?提供了支持(更有资格人士的研究)吗?主持人索要了吗?
- 专家意见:对该特定议题有具体专业知识吗?引证当前研究吗?其他权威赞同/反对?
- 实验:其他研究者重复/独立证实了吗?
- 统计资料:来源可靠吗?
- 问卷调查:样本真正有代表性(总人口成员有平等被选机会)吗?问题清楚无歧义且客观吗?邮件调查有多少未回答?其他调查证实了吗?
- 正式观察:观察者在场是否破坏了所发生的事?观察时长足够吗?结论过度概括了吗?
- 研究评论:结论相对所涵盖研究合理吗?遗漏了相关研究吗?
- 附加的总问题:这个证据与议题相关吗?不相关就不值得考虑,无论其他方面多优秀。

**3. 评价你信息来源的论证(总结→逐句提问法)**
- 工具承接:第七章教你用"总结"压缩跨段论证,第十七章给了写总结的六步,本章教你用同一篇总结反过来"评价"论证。
- 操作:把总结每句编号,对每句提出问题。书中对"取消成绩"总结的5句各配一组问题(例:"青少年从6岁到20岁或22岁,心头就一直缠绕着对低分的恐惧"→"这些年龄段之间的所有青少年都恐惧低分吗?他们所有人都如此吗?这种恐惧严重吗?")。
- 第二例:心理学家乔伊斯·卜洛泽对"妻子与同性恋男士共事、丈夫反对"的7点回答,逐条分析——既找出她的一般化(把个案扩展为所有同性恋恐惧者的性格特点)、假定(假定女人公平对待自己而丈夫非理性),也确认第3点"理性的人都不会质疑"。
- 提问的三个好处:防止凭第一印象草率判断;迫使你逐部分评价论证(而非接受一个总体印象),确认优点与缺点;常为你提供一个组织思想的结构。
- 你对这些问题形成的答案就是你对论证的回应;写作回应时可循问题顺序或自选组织模式,以内在一致性和你想要的强调重点为准。

**4. 作出重要的区分(6种)**
1. 把人与思想区分开来:可钦佩的人可能出错,卑劣的人可能说对;性别、肤色、国籍、宗教不是接受或拒绝思想的合适依据。
2. 把所说的与如何说区分开来:风格与实质不同;最清晰优雅的表述者未必拥有最合理的思想(引圣·奥古斯丁:关注的是证据,不是雄辩)。
3. 把人们为什么这样认为与他们认为的事情是否正确区分开来:动机可疑不必然破坏立场;思想的合理性取决于它如何适合现实的情况。
4. 把个人与群体或阶层区分开来:不草率地把个人特征归属于群体,反之亦然。
5. 把偏好的问题与判断的问题区分开来:偏好(情趣爱好)无可辩论;判断(对事实和理论的解释)可以且应当被质疑。
6. 把熟知性与正确性区分开来:熟悉的思想不必然正确;判断正确性时应无视熟悉与否,以开放眼光看两方面。

**5. 判断的表达(6条指南)**
前提:表达一个判断的行为可能改变该判断——在文字准确表达之前,把它视为"无形式的"。
1. 力求一个平衡的观点:平衡=反映议题全部微妙性和复杂性;主导观点在争议和激情高涨时裹挟大多数人(流行视角、流行论证、流行词语);拉什迪《撒旦诗篇》例——言论自由是可敬原则,但理智平衡者同时提醒"尊重其他宗教信仰"的原则(John Leo、John Esposito 的制衡表述);自尊例——勒纳抵御"自尊总是好的"的流行看法,区分"赢得"的自尊与"现在感觉良好"的自尊。做到平衡须愿意寻找被忽视的一面,并在有充足理由时质疑主导观点。
2. 处理可能性:证据不足以确定"吸烟导致肺癌""观看暴力必定伤人"时,不负责任者假装确定性——智识上不诚实;承认"我不能确定"不丢人反而是美德,但负责任的思考者必须进一步解释可能性有利于哪个判断(证据"提示"而非"证明")。
3. 让主语适当具体:同一句话从"今天的大学生"收窄到"今天这所大学的学生",证据只覆盖一个大学时只有最后一个判断合理——其余三个概括过度。
4. 使谓语准确:"和平已经/能够/必须/应当/有可能/将要实现"含义全不同;"上帝死了"至少有8种可能解读,作者不澄清,受众既不了解情况也不能被说服。
5. 包括所有适当的限定语:时间、地点、环境限定语越多,判断越可辩护(全国妇女组织例:几乎每个词都是限定语——"美国40岁以上、未读过大学的男人倾向于反对全国妇女组织（National Organization for Women）提出的妇女解放的观念")。
6. 避免夸大其词:对惯用极端词汇的人,听者被迫做"缩到现实比例"的转化,并视其报告不可靠;他人也会这样看你。不能确定准确性时,宁选低估不选高估——出错时至少保有"控制和约束的意识"的优雅。

**6. 全书策略部分五步总清单(第14–18章收束)**
1. 知道自己,对你的思维习惯可能损害你处理议题的方式保持警惕(第14章)。
2. 敏锐地观察,并反思你所看到的和听到的(第15章)。
3. 确定议题时,通过列举它的各个方面并对每个方面提出探究的问题来清楚阐述它(第16章)。
4. 进行透彻的探究,获取所有相关的事实和有见识的观点(第17章)。
5. 评价你的发现结果,然后形成并表达你的判断(第18章)。
- 这张清单可随时当检查表使用。

**7. 应用练习**
- 练习1:用本章方式分析5段立场短文(a 感觉直觉优于推理;b 利他主义是自私幌子;c 婚姻制度已失去生命力;d 不应允许严格课堂考勤;e 对罪犯应强硬、规定明确刑期),须超越第一印象、避免第十三章的思维错误,判定你在哪些方面赞同/不赞同。
- 练习2:把本章所教应用于你对第十七章某个应用练习的探究结果。

## 逐字摘录

- "判断是通过证据考察和仔细推理得出的结论。它们是思考的结果。不像感觉，判断不是自发和无意识的。"(第18章·形成判断)
- "判断是评价和推理的结果，这一事实并不保证它们的价值。有愚蠢的也有明智的判断，有肤浅的也有深刻的判断。"(第18章·形成判断)
- "然而，他们获取的大量事实要有用处，就必须进行解释 。"(第18章·形成判断)
- "事实上，因为在其他领域，信息可能不太清楚或比较零碎，各种观点也许更激烈地相互冲突，所以一个判断的质量可能更多地取决于评价。"(第18章·形成判断)
- "评价证据在于提出并回答恰当的问题。"(第18章·形成判断)
- "一个附加的问题可适用于各种证据：这个证据与正在考虑的议题相关 吗？如果不相关，那它就不值得考虑，无论它在其他方面是多么地优秀。"(第18章·形成判断)
- "首先，这可防止你根据第一印象草率地作出判断。其次，这让你逐一评价论证的每一部分（而不是满足于接受一个总体评价），从而确认优点和缺点。再次，花时间提出恰当的问题经常能提供一个用以组织你的思想的结构。"(第18章·形成判断)
- "这样的反应是非理性的，因为思想与拥有思想的人并非同义语：可钦佩的人有可能出错，而卑劣的人也可能说对了。而且，一个人的性别、肤色、国籍或宗教并不是接受或拒绝他或她的思想的一个合适的依据。"(第18章·形成判断)
- "风格与实质是相当不同的问题。令人遗憾的是，进行最清晰和最优雅表述的人并不总是拥有最合理的思想。"(第18章·形成判断)
- "就像圣·奥古斯丁（Saint Augustine）说过的：“我们对一个人的关注不在于他讲得多么雄辩，而在于他的证据是什么。”"(第18章·形成判断)
- "但重要的是我们应记住，不足道的动机并不必然破坏其立场。一个思想的合理性并不取决于支持它的那些人的动机。这取决于该思想如何适合现实的情况。"(第18章·形成判断)
- "偏好的问题事关情趣爱好，这对辩论没有什么意义。然而，判断的问题则事关对事实和理论的解释，这是可以辩论的。因此，质疑判断的问题是适当的。"(第18章·形成判断)
- "但是，熟悉的思想并不必然是正确的。相应地，在对正确性作判断时，我们应该忽视对该思想是熟悉还是不熟悉。"(第18章·形成判断)
- "表达一个判断的行为有可能改变该判断。因此，无论你头脑中对一个议题的判断可能有多么清晰，你最好把它看作是无形式的，直到你用文字准确地表达它为止。"(第18章·形成判断)
- "在这样的时候，不负责任者经常提高他们的声音，选择更有力的言辞，并且假装 确定性。这是一个严重的错误，首先是因为这种假装很少能愚弄好的思考者，而更重要的是因为这在智识上是不诚实的。"(第18章·形成判断)
- "只要我们作出真诚的努力去获取实现确定性所必需的证据，而不是故意地选择骑墙观望，那承认“我不能确定地说出这种情况下正确的判断是什么”并不丢人。相反，这样做是一种美德。"(第18章·形成判断)
- "无论何时当你不能达成确定性时，就集中关注可能性。"(第18章·形成判断)
- "如果证据涵盖的只是一个特定大学的学生，那只有最后一个判断可能是合理的。而其他的三个概括过度了。"(第18章·形成判断)
- "让受众猜测你的意思，这是不负责任和自我拆台的。"(第18章·形成判断)
- "如果你要自己的判断经得起他人细致入微的检验，那就避免所有的夸大其词。在你不能确定自己判断的准确性，你应倾向于选择低估的陈述而不是高估的陈述。"(第18章·形成判断)
- "4．进行透彻的探究，获取所有相关的事实和有见识的观点。"(第18章·形成判断)
- "5．评价你的发现结果，然后形成并表达你的判断。"(第18章·形成判断)

## 辅导提示

- 用户抛出一个观点问"你觉得靠不靠谱" → 先分清他给的是判断还是感觉:判断必须有被考察过的证据;问他"支撑你这个结论的证据属于哪一种类?"再按11种证据的专属问题逐个自查,并先过总闸:与议题相关吗?
- 用户说"我看过一篇文章,写得很有道理" → 教总结→逐句提问法:让他把那篇文章的核心论证压成5句左右编号总结,再对每句提出"所有人?总是?因果成立吗?"式问题(用书中"取消成绩"总结做示范),然后问他:哪些句子经住了你自己的提问?
- 用户因人废言("那人品行有问题/不是科班出身,他的话不用听") → 区分1(人与思想):可钦佩的人可能出错,卑劣的人可能说对;让他把"这话是谁说的"与"这话本身成立吗"写成两栏,重答一遍。
- 用户被漂亮的表达打动 → 区分2(所说/如何说)+圣·奥古斯丁之问:把原文的修辞剥掉,让他只列出证据,再评价。
- 用户用动机驳立场("他们反对涨价只是因为利益") → 区分3:发现参议员与手枪制造商的联系"提出了有趣的问题",但动机不必然破坏立场;引导他单独检验立场本身是否适合现实情况。
- 用户说"这是常识/老说法,不用验证" → 区分6:熟知性≠正确性;问他"如果第一次听到这句话,你还会这样点头吗?"
- 用户要写下结论 → 用表达六指南逐项照镜子:主语是不是比证据宽(概括过度)?谓语是不是把"应当"写成了"已经"?有没有假装确定性?敢不敢把每个夸大词换成低估版?
- 用户坚持"两边都有道理所以我不站队" → 回到第十七章告诫与本章"处理可能性":不假装确定性不等于放弃判断,负责任的义务是解释可能性有利于哪个判断。
- 练习:从本章应用练习的5段短文(a-e)里挑一段你原本赞同的,按逐句提问法写一页分析,标出你赞同与不赞同的确切位置(改编自本章应用练习1)。
- 复习钩子:让用户默写五步总清单,对照自己最近一次"下结论"的过程,指出跳过了哪一步(改编自本章末尾策略总结)。
