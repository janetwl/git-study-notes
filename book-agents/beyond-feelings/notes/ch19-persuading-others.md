# 第十九章 说服他人

定位:全书终章。第十八章结束时你以为思考已经完成,本章补上最后一环——慎思的判断"值得共享":如何用写作和讲话把你的判断有效地交给未持立场者和反对者,从而把批判性思考的收益扩大到自身之外。

## 核心论点

**1. 说服的定义与难度**
- 说服 = 如此有效地表述你的观点,以至于未持立场的人倾向于同意你,而不同意你的人被激励重新考虑自己的观点。
- 中立者只在你论证了自己观点的合理性时才开放听取;反对者倾向于拒绝,因为你的观点质疑了他们自己——接受它可能意味着抛弃他们慎思过、并与自我意识交织在一起的旧观点。
- 难度校准:反思你自己对否定自己观点的抵制——即使经过一学期批判性思考训练仍难公正听取,就不能期待未受训练的人反应更宽大。

**2. 说服的11条指导原则(每条针对一个具体难题)**
1. 尊重你的受众:你若认为对方愚蠢或认知不诚实,必会直接或间接(语调、选词)透露,对方会感到受辱而更难被说服;关键是没有明确证据就不要做此认定——问问年龄、性别、种族、民族、家庭背景、宗教、收入水平、政治派别、教育程度、个人经验等因素能否解释分歧;能解释,就有理由把异议看作慎思和诚实的。注意:不必声明尊重(声明听起来缺诚意),致力于尊重的感觉本身。
2. 理解你读者的观点:仅有自己观点不够;人们的观点对他们自己很重要,被无视会感到被冒犯;影响他人前必须知道其立场。三种常见情况:
   - 情况1 读者已在文章/书/演讲/对话中提出想法 → 回顾其主张与推论,判断强项弱项;
   - 情况2 读者尚未表态(如写信给赞助有争议剧集的公司总裁) → 预先考虑"最坏结果"(他强烈支持赞助),用想象力提出他会问的问题;
   - 情况3 写给所有持反对意见的人(最常见) → 找出对方频繁重复的论证和主题;最有影响力的思维错误代表对说服的最大挑战。
3. 从你与读者共同的立场开始:以"听我说,你是错的"开场会把读者推到防守乃至敌视,他们会只顾估量你论证的弱点——若他们因此读得不合理,过错更多在你。肄业生申请重新入学例:学生第一版开场是"我认为应允许……因为每个学生都应有第二次机会。你们说……",等于迎头顶撞;改写版先承认"大学教育是他们必须持续争取的一种特权，而不是一种不可侵犯的权利"、占用时间空间伤害认真学生等共同立场,然后"但是"仍可出现——只是在读者已被证明理解议题范围之后。
4. 采取积极的态度:只要可能,建构自己的事项而不是摧毁对方的;不是说不能指出对方弱项(有时那是唯一负责任的做法),但直接批评观点显得比批评人严厉、简短批评显得耗时长久,负面情绪会使读者防卫。枪支控制例:两个回应都反对原文三点,回应1只是逐条"你是错的",回应2则构建另一种见解——能不直接引用读者反对意见就有效提出并支持自己观点,就尽量这样做。
5. 尽可能让人理解你的论证:谨慎处理分歧最尖锐之点(它们是最大障碍);夸大地陈述己方观点会强化读者对自己观点的确信,并给对方提供摧毁性反驳的机会("自卑情结"例、"如果他人尊重我们,我们就更值得尊重"例——夸大结果使本倾向同意的读者拒绝整个想法)。做法是把强陈述改写为有保留的陈述("某些机会/相当快速/通常是"替代"机会/突然/极其"),不妥协立场,却更有效地表述。
6. 承认对方有道理之处:牢记"大多数有争议的问题中,没有一方是拥有全部真理的";承认要具体、详尽(必要时),不是开头放一句"每个人都有道理"然后一头栽进自己观点;性教育项目例——承认成熟水平差异、家庭才是理想场所,这些承认不损害反而加强你的论证,因为它们表明你对议题较大方面的把握。读者不会对你比你对他们更宽宏大量。
7. 不要忽视任何相关事实:发现支持对方而非自己的事实时,忽视的诱惑很强烈;但论证的目的不是击败他人而是发现真理的全部复杂性;隐瞒任何部分真理无人获胜。反贫困项目例:发现未广泛报道的、暴露己方阵营项目低效浪费的报告,若确信相关,诚信要求提到它、处理它、并相应修改观点。
8. 不要用论证压倒读者:少于3000字的短文不可能是全面定论,严肃作者也不装作是;堆细节例证到"不暗示议题还有另一面",读者会判定文章单方面、不平衡;只提供与读者最相关、最有说服力的论证。也避免强迫式结尾——"我已经证明了""无可反驳""理性的人不会犹豫":短文中你不可能"证明"任何东西,让读者自己下判断才明智。
9. 集中于最可能说服读者的论证:不同论证吸引不同参照框架的读者。参照框架表(以"美国是否应介入其他地区冲突"为例):
   - 道德和/或宗教:支持方"强者的道德义务是保护弱者""暴行实施时袖手旁观是不道德的";反对方"以德报怨、以爱报恨""现代战争惩罚行凶者时也惩罚受害者";
   - 政治和/或实践:支持方"技术使星球变小,没有地方处于国家利益之外""拒绝制止暴政等于鼓励暴政";反对方"世界变小更需抵制介入欲望""国外战争耗尽资源增大自身弱点";
   - 哲学:支持方"一个自由的国家有义务维护任何地方的自由";反对方"战争使所有介入的人堕落"。
   用读者会被说服的论证,而不是你个人觉得最有说服力的。
10. 决不使用你认为不合理或无关的论证:这是第9条的限定条件——真诚和尊重事实是作者最重要的品格,缺了就没有真正的说服,只有巧妙的表述;若你确实相信只有一个论证值得考虑,就用那一个。
11. 为你的观点得到认可而容留时间:别指望读者立即抛弃己见;最佳预期是他们被触动、重新考虑,你的洞见"最终"导致修改——可能是下周或明年;这不必然反映你的技巧,只是人们与观点间的纽带不易打破。
- 本章末尾给出11条的总结性清单,可作为说服性写作的自查表。

**3. 反面与正面实例(餐厅投诉信对比)**
- 缺乏说服力的版本:始于指责("学生们厌恶低劣的食品……"),违反原则3(无共同点)、原则5(讽刺、夸大:"死苍蝇""提高学生的士气"式的酸)、原则1(暗示员工故意肮脏、轻率判断行政人员"不正视这些问题"),指控无例子支撑;分析:经理要么被预设为不诚实(那就不该给她写信而该写信给她的上级),要么尽责——而无所不包的控诉必然让她拒绝整个陈述,并强化其看不到缺点的人性倾向。
- 有说服力的版本:从"什么样的学生常抱怨餐厅"的共同判断开场(以自己室友约翰为例承认抱怨者的不成比例),肯定"我们餐厅的服务和食品质量通常是好的",收窄到两点具体改进(排队15分钟、肮脏的碟子和餐具),给对方留台阶("可能出于效率考虑""或许他们太忙了没有注意到"),结尾承认两点不能让爱抱怨者满意、但会让餐厅成为就餐的更佳场所。任何一个正常尽责的经理都会把这封信视为理性、善解人意的成熟学生的作品,并可能想去改善服务——"也就是说,它是有说服力的"。

- "简单的回答是，因为慎思的判断值得共享，而且，表达这些判断的方式可能强烈地影响他人对其作出反应的方式。"(第19章·说服他人)
- "说服 意味着如此有效地表述你的观点，以至让在该议题上未持立场的人将倾向于同意你的看法，而那些不同意你的人将被激励起来重新考虑他们自己的观点。"(第19章·说服他人)
- "中立的人将以开放的心态听取建议，但只在你论证了自己观点合理性的时候。"(第19章·说服他人)
- "如果你认为自己试图说服的人是愚蠢的或在认知上不诚实，那你必定会透露出这种信念，如果不是直接地、那也会间接地在你的语调或选词中表露出来。"(第19章·说服他人)
- "问问自己，什么可能是他们不同意你观点的原因。考虑所有可能影响一个人看法的因素，包括年龄、性别、种族、民族、家庭背景、宗教、收入水平、政治派别、教育程度和个人经验。"(第19章·说服他人)
- "不应觉得你需要声明对读者的尊重。这样的声明有听起来缺少诚意的效果。致力于尊重的感觉；如果能做到这一点，你就没有必要刻意声明。事实将表明一切。"(第19章·说服他人)
- "许多人错误地认为，要有说服力，只需要掌握自己的观点就够了。"(第19章·说服他人)
- "一种思想路线越是频繁地表达，表达它的人数越多，它可能在形成人们观点上的影响力就越大。思维中最有影响力的错误代表了对说服的最大挑战。"(第19章·说服他人)
- "如果你开始说（即便不是直接如此说，也是大意如此）：“听我说，你是错的，我这就解释给你听”，那你就把读者推到了防守的地位，假如不是完全敌视的反应的话。"(第19章·说服他人)
- "只要有可能，就建构你自己的事项，而不是摧毁反对方的事项。"(第19章·说服他人)
- "但是，请记住，直接批评反对方的观点将总是比直接批评赞同此观点的人显得 严厉，一个简短的批评显得 耗时长久，而且，只要是觉得 你的态度是负面的，就会使你的读者处于防卫状态。"(第19章·说服他人)
- "第一个回应只是摧毁该文的观点；第二个回应则构建了另外一个观点。"(第19章·说服他人)
- "应当始终十分谨慎地处理你与读者间分歧的最尖锐之点。这些分歧点代表了对说服的最大障碍。"(第19章·说服他人)
- "我们所有人过高评价自己观点的自然倾向，使我们难以承认反对方的观点也有其优点。只有牢记在大多数有争议的问题中，没有一方是拥有全部真理的， 才能克服这种倾向。"(第19章·说服他人)
- "而且，追求真理的全部责任要求我们不是勉强地而是欣慰地、毫不犹豫地承认真理。"(第19章·说服他人)
- "请记住，读者对你可能并不比你对他们还要宽宏大量。只有当你在这些认可当中是开放和诚实的，你才能期待他们也会如此。"(第19章·说服他人)
- "但是，论证的目的不是击败他人，而是通过观点的交流发现真理的全部复杂性。当这样做时，人人都赢。当真理的任何一个部分被掩盖起来时，无人获胜，即使看起来也许是某人赢了。"(第19章·说服他人)
- "在有争议的议题上，少于3000个词的文章不大可能是全面定论的。而且，严肃的作者不会试图传达这样的印象。"(第19章·说服他人)
- "在一篇短文中你不可能“证明”任何事情。尽管对你而言，证据“看起来是无可反驳的”，你也可能认为是“毫无疑问的”，但请记住，让读者作出自己的判断才是明智的。"(第19章·说服他人)
- "不同的论证会吸引不同的读者。正如了解你的读者对该议题的观点是很重要的一样，使用将会吸引他们的论证也是很重要的。忽视他们的参照框架，选择你自身觉得具有说服力的论证，那是错误的。"(第19章·说服他人)
- "真诚和尊重事实是作者最重要的品格。没有这些品格，就没有真正的说服，而只是巧妙的表述。"(第19章·说服他人)
- "除了罕见的情况，你应该期待的最佳情况是，他们将被触动，根据你所说的重新考虑该议题，而你的洞见将最终 导致他们修改自己的观点。"(第19章·说服他人)

## 辅导提示

- 用户说"我明明是对的,他们为什么不听" → 先照出隐含假设:说服的失败常被归因于内容,而本章把大半失败归因于姿态。让用户把他的原稿/原话对着11条清单过一遍,先查三条最容易踩的:有没有从共同立场开始(原则3)、有没有夸大地陈述分歧点(原则5)、有没有"我已经证明了"式的强迫结尾(原则8)。
- 用户准备写一封投诉/反对信 → 用餐厅两封信做对照教练:让他标出草稿里的"没有始于共同点""讽刺冒犯读者""给读者留下不快的印象"各在哪一句,再仿正面版本重写:先承认对方的难处与已有的好成绩,再把指控收窄到一两个能举出例子的点(改编自本章应用练习的写作任务:另用一张纸说明你的读者是谁,并解释你的读者分析)。
- 用户说"对方就是蠢/坏,没什么好说的" → 原则1反问:你能列出明确、令人信服的证据吗?让他试着用"年龄、性别、家庭背景、宗教、教育程度、个人经验"逐项检查对方的立场——如果能找到一项可解释分歧的因素,按本章要求就该把异议看作慎思和诚实的;如果真的认定读者不诚实,本章还有一句狠话:那就不要写给这样的读者看。
- 用户"我全知己方观点,写出来自然有说服力" → 指出这正是要纠正的错误("要有说服力,只需要掌握自己的观点就够了"),然后带他做情况2/情况3的功课:对方最常重复的论证是什么?哪种思维错误在对方阵营里最有影响力?——那才是你真正要说服的东西。
- 用户赢了每一场辩论却说服不了任何人 → 原则4:直接摧毁对方观点"显得"比建设自己的观点严厉得多;把"你是错的×3"式回应改写为"这里有另一种见解"式。
- 用户犹豫要不要隐瞒一条不利事实 → 原则7直接对撞:"论证的目的不是击败他人,而是……发现真理的全部复杂性";问他:如果对方后来发现了它,你这次的"赢"还剩下什么?
- 用户焦虑"发出去三天还没人改观点" → 原则11:"最终"可能是下周或明年,这不是对你技巧的评价;把目标从"立即接受"重设为"被触动、重新考虑"。
- 用户问"我该用哪个论据打动人" → 原则9参照框架法+原则10的刹车:先判断读者的参照框架(道德/宗教、政治/实践、哲学),在吸引他们的论证里选;但决不使用你自己认为不合理或无关的论证——第10条是对第9条的限定。
- 收官练习:从本章39个争议议题(或用户自己的议题)中选一个,"深度探讨一两个方面,比肤浅地处理大量的方面要好",写一篇说服性短文,并附读者分析(改编自本章应用练习)。
