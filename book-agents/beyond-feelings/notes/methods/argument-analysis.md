# 方法卡 · 论证拆解与评价

**何时使用**:用户转述别人的道理(文章/演讲/辩论)要判断靠不靠谱;或用户自己的结论其实是"感觉"要包装成论证;或陷入非此即彼的辩论想找出对方推理漏洞。

**原理**(第七章;贯穿全书的评价核心):
- 论证三义:争吵/意见交流的理想合作/**支持一个判断的推理思路**——取第三种。论证是"文字方程式":把它写成前提+推理+结论就能检验。
- 逻辑评价四原则:①前提要么真要么假;②推理要么有效要么无效;③正确的前提加上有效的推理等于合理的论证;④任一缺陷=不合理。
- 关键教点:**论证不合理≠结论假**(健美例:假前提可以碰巧推出真结论)——评价论证是评价"支持关系",不是裁决结论生死。
- 隐蔽前提最难对付:段落越长越难确认;先把它们揪出来再评价。

**用法步骤**:
1. 指认结论:找"因此/所以/从而"等指认词;没有就用检验问句"其他断言支持或加强了哪一个断言?"
2. 列前提:把每个前提显式写成一行;含"'总是/所有/从不'这类暗含普遍性的限定词"要单独检查。
3. 逐前提一问:它是真的吗?证据属于哪类(接 evidence-review 卡)?
4. 对结论固定两问:它是否从前提逻辑推出?**是否还有其他同样可推出的结论?**
5. 困难论证五指南:超长段落先做总结;成分不明时问"作者想让我接受什么思想";多前提逐个击破;对立双方之间找第三选项(十诫例);隐蔽前提先揪出(四例:肉体吸引、自尊心、禁书、纯净水)。
6. 双面倾听:支持己方的论证也要按上述流程过一遍(布什可卡因例)。

**边界**:
- 不要因为对方论证烂就宣布其立场假(反之亦然)——"去给他造一个好论证"才是建设性动作。
- 攻击提出者≠攻击论证(见 criticism-response 卡);评价对象是推理思路,不是人。
- 第一步总结若做不好(超段),评价会整体失真——先总结再评价。

**出处**:第一篇·第七章《什么是论证?》(notes/ch07)
