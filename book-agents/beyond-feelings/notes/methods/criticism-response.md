# 方法卡 · 面对批评的反应体检

**何时使用**:用户刚被反驳/被否定/被审稿,正在气头上;或用户复述别人批评时明显在辩护;或问"我明明是对的为什么这么难受"。这是本向导最有温度的用武之地——先接住面子机制,再练反应纪律。

**原理**(第十二章,五个反应错误):
- 总根源:保全面子/自我形象。"我们一旦接受了某个观点，自尊心就使我们不愿承认自己是错的……我们宁可费力地为自己的观点寻找新的支持，也不坦然面对明显与自己的观点相矛盾的任何新事实。"
- 反应错误总定义:用来解释对我们观点的批评的顾全面子的花招。
- 五种花招:自动拒绝("未给予公正倾听就拒绝批评")/转换话题/转移举证责任("要求别人否证你的断言")/稻草人(把不实之词强加于人再揭其虚妄)/攻击批评者("想法和人并不是同义语")。
- 举证责任规则:"规则就是，任何提出该断言的人承担支持它的责任，而且，该断言越是背离有见识的人们的看法，提出此断言的人支持它的责任就越大。"

**用法步骤**:
1. 面子三问诊(定位触发器):这个观点连着你哪个**自豪领域**?哪个**特定角色**(如牺牲型父亲萨姆)?怕哪个**特定观察者**知道?
2. 对照名录检查刚才的反应:是否秒拒(没听完)、是否岔开话题、是否"你倒是证明我错啊"、是否回击了一个对方没说过的立场、是否扯对方身份。
3. 理想回应台词操练:被稻草人时说出"我宁愿听到你回答我实际所说的话"。
4. 建情感距离:把观点当作"可保留或抛弃的**所有物**"而非自我的肢体——批评所有物不伤所有者。
5. 公正倾听流程:先用自己的话复述批评直到对方认可,再决定采纳/反驳/悬置。

**边界**:
- 话题本不当时回避是合理的(书中给转换话题设了合法边界条款);定罪前先查"该不该在此时此地谈"。
- 质疑批评者的诚信**并不总是禁**——禁的是以人代论(用身份替代对论证的回应)。
- 目标是公正倾听,不是来者照收;自动拒绝的反面不是自动接受。

**出处**:第二篇·第十二章《反应的错误》(notes/ch12;"公正倾听"关键词同时出现在第十三章解毒清单)
