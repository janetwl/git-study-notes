# 方法卡 · 错误组合会诊(总诊断路径)

**何时使用**:用户的想法"哪里不对但说不清"——这是向导的主诊断台。也用于:多人集体轻信某事(福克斯"民科演讲"实验:55名教育者中计)、一段争论里毛病成串出现、或错误之间互相掩护。

**原理**(第十三章):
- 组合公理:"虽然共同发生错误的组合有可能数不胜数，但它们都有一个共同之处：它们对批判的思考形成的障碍比任何一个单独错误都要大。"
- 万恶总根:"我的更好"常是链条起点。典型链:我的更好→反对变化偏见→有偏见的证据考量→草率的结论。
- 四类错误按思维过程阶段排列(立场→程序→表达→反应),各有解毒名录:立场7项(ch9)、程序6项(ch10)、表达6项(ch11)、反应5项(ch12)——每项在原书为"如何辨识+如何解决"格式。
- 术语纪律:"知道正确的术语是有好处的，但更重要的是认识到推理在哪里出错了，并且能够根据所涉及的问题来解释错误。"
- 三案例模板:克劳德(党派之争:我的更好→高估己方低估对方→过度简单化→被质疑时面子手法;"投入越深越难认错、学到的越少")、萨姆(烟瘾:遵从→要么要么→面子归因→无根据假定×2→过度简单化)、史蒂芬(学业:无根据假定→刻板成见→拒绝合理解释→攻击批评者)。

**用法步骤(会诊五步)**:
1. **定阶段**:毛病出在想问题的哪一步——起点立场?处理证据?说出来的话?面对批评?(四类各挂卡:position-errors-scan / procedure-errors-scan / expression-errors-scan / criticism-response)
2. **找第一错误**:沿时间线回溯,链条上最早的那个(通常是"我的更好"或无根据假定)。
3. **顺链条**:看它带出哪些后继错误,组合发作要一起解。
4. **数面子投入**:越难认错,面子绑定越深——接 criticism-response 三问诊。
5. **不执着命名**:向用户解释"推理在哪里出错",术语只做辅助记忆。

**三岔辨析**(易混三兄弟:过度简单化/草率结论/假定):
- 是否说出:假定常未明说;草率结论、过度简单化是已说出的断言。
- 论证角色:假定当隐含前提;过度简单化当完备性主张;草率结论当证据不足的断言。
- 检验方式:假定→挖出来评(ch9);过度简单化→补另一面(ch10);草率结论→穷举可能结论再配证据(ch10)。

**边界**:
- 原书计数句"6+6+7=19"与实列名录(7+6+6+5=24)有出入(导言所列"转移议题"无专节)——以各章实际名录为准,不必硬凑数。
- 会诊不是定罪表演:给用户的是一次"你自己重走一遍推理"的机会(先照镜子,再练习)。
- 集体轻信不必羞耻:福克斯实验正是"专家讲台+熟悉感"的双重操纵。
