# 方法卡 · 证据审查(11类型×问题包)

**何时使用**:用户拿个案、新闻、专家话、统计数据、研究报告来支撑一个结论;或要做决定却说不清证据分量。本章问题包是全书最大的可复用资产。

**原理**(第六章;接口第十七、十八章):
- 证据与观点的分工:陈述观点是"告诉"他人你的看法,提供证据是向他人"表明"你认为有意义的事情。
- 两大习惯:形成观点**前**检查证据的质量和数量;表达观点**前**温习证据。
- 证据11类型,每类有专属"评价可询问"问题包:个人经验/未公开的传说/公开的报道/目击者证言/名人证言/专家意见/实验/统计资料/调查/正规观察/研究评述。
- 总闸问题是**关联性**(班级规模案例:信息课程 vs 技巧课程——证据可能真实但不相关)。
- 统计三问(伯斯特):"谁造出了它？在造出它时出于什么目的？它是如何被造出的？"
- 偏见六迹象自查表;"明确声明"的排序按熟悉程度而非可靠性,须警惕。
- 充分性三档:确定性(超出合理怀疑)→可能性(证据优势)→不充分,**则悬置判断**。

**用法步骤**:
1. 归类:把用户手里的每条证据按11类贴标签,问"它属于哪类?"
2. 用对应问题包逐条追问(个人经验→样本与记忆可靠性;专家意见→领域/同行评审/有无相反共识;报道→消息来源与议程;实验→是否可复制……详见 ch06 笔记清单)。
3. 统计/调查数据先跑伯斯特三问,再看样本类型(随机/系统/分层)与措辞效应。
4. 关联性总闸:"这个证据与正在考虑的议题相关吗?"不相关,再优秀也出局。
5. 偏见六迹象对照自己:我是不是只对违逆我的证据做这些检查?
6. 输出三档判定;落到"不充分"时明确说:不作判断,直到有充分的证据可以利用。

**边界**:
- 熟悉≠可靠;清楚≠正确。
- 悬置判断是主动的认识论立场,不是拖延;等得起的议题才等,须在期限内决策的议题按"证据优势"档处理。
- 11类排序在原文按出现频率而非可靠性,别照排序当等级表用。

**出处**:第一篇·第六章《证据是什么?》;接口:第三篇·第十七章(探究充分性)、第十八章(评价证据=提恰当问题)
