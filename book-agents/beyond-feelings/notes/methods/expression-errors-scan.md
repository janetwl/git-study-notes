# 方法卡 · 表达错误六检测(说与写的输出端)

**何时使用**:检查用户(或对手)写出来/说出来的东西——陈述前后打架、车轱辘论证、广告腔、"专家说所以可信"、打比方充数、煽情/讲传统/装中庸。表达错误按书中分类元逻辑是"最易指认矫正"的一类,适合当场练。

**原理**(第十一章,六个表达错误):
1. 自相矛盾——违反矛盾律("不可能在同一时间以同样的方式作出既真又假的陈述");豁免条款:若两陈述可作不同解释则不成立(雇凶杀人/体重/罗斯福三例演示"检查→考察可否解释→判定→重写")。
2. 循环论证——证据只是观点换词复述;扩展包装版更难察觉。
3. 无意义的陈述——语法正确但既不证实也不证伪("伴随形态:'无意义的说明'"——对无道理的理由作说明;广告语检测法)。
4. 误用权威——名人崇拜版+微妙版:**跨领域**专家冒充(权威在己领域≠在议题领域)。
5. 错误类比——合法性判据:宣称的相似性必须**真实且与论题相关**(炒鸡蛋/地球运动例)。
6. 非理性的诉求,六亚型:情感/传统/适度/权威/共同信念/宽容;每型有理性-非理性双面判据。

**用法步骤**:
1. 拿陈述做矛盾测试:有没有对X同时断言A与非A?先排除"可解释"豁免(词义转换?)再定罪。
2. 抽掉证据看观点:论点重述一遍当论据=循环。
3. 无意义检测:想象什么观察能证明它为假?证明不了即空话。
4. 权威三查:此人是谁的权威/议题是否其领域/有没有同行相反意见(接 evidence-review)。
5. 类比审计:列出被比双方的相似点,逐点问"与论题相关吗"。
6. 总判据一句话:"区别理性和非理性诉求的最好办法就是看这种诉求是否伴随着你为何应当接受它 的解释。"有解释并证明→理性诉求可用;无解释或解释不可信→非理性,驳回。

**边界**:
- 诉诸情感/传统/适度**不总是错**(每种都有理性使用形态),别见修辞就喊打——关键是伴随解释。
- 表达错误好指认,但立场/程序错误更隐蔽,单向输出检查通过≠推理过程干净(接 procedure-errors-scan)。
- 术语纪律(ch13):指认错误时解释"推理在哪里出错"比甩名词有用。

**出处**:第二篇·第十一章《表达的错误》(notes/ch11)
