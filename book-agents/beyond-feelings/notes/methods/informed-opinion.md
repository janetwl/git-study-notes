# 方法卡 · 形成有见识的观点

**何时使用**:用户问"我可以有我的观点吗""我的想法有没有分量";在道德议题上下判断;或把"我有权这么想"当免于论证的挡箭牌。

**原理**(第五章):
- 批判性思考语境下,"观点"指**判断的表达**而非喜好的表达;喜好(咖啡口味)无所谓对错,判断可以被证据检验。
- "有权持有观点"≠"观点正确"≠"可任意按其行事(不伤害他人)"。
- 各种思想很少具有同等性质——批判性思考的任务是把较有价值的与较无价值的区别开来,最终确定最佳者。
- 有见识观点三要件:更坚实的事实基础、细考过的证据、恰如其分的支持("一两句观点配若干页支持"的比例示范)。
- 道德判断三标准:义务、理想、结果;冲突时优先最重要者;结果做六维度检验;混合结果选较大善或较小恶。
- 错误观念谱系:培根四类"假象"+洛克"易错三型"+作者增补第四型(从不重检旧观点者)。

**用法步骤**:
1. 定性:你说的"观点"是偏好还是判断?偏好直接放行,判断进下面流程。
2. 暂停(爱比克泰德法):第一印象出现时,先搁置,不让它直接上岗。
3. 比例自检:我的观点后面,站得住的证据有几页?若只有一两句,承认它是"观点尝试"而非结论。
4. 三要件补考:补事实基础→细查正反证据→把结论强度调到证据允许的水平。
5. 道德议题:用义务/理想/结果三把尺各量一遍;结果尺做六维度检验,混合局面选较大善或较小恶。
6. 把"观点当事实"的默认模式切换成"观点可被推翻的判断"模式(ch05 有两栏对照表)。

**边界**:
- "你将可控制自己的观点,而这比让它们控制你具有相当大的优势"——目标是掌控观点,不是取消立场。
- 不伤害他人是表达与行动的外部底线,不是内部论证标准。
- 专家也会错(12+案例),但不因此贬低一切专家意见——见 evidence-review 的分类检验。

**出处**:第一篇·第五章《你的观点有多少根据?》(notes/ch05)
