# 方法卡 · 形成判断与说服表达(策略后半程)

**何时使用**:用户材料看得差不多了要下结论;或写好了观点想拿去服人;或在争论里"赢了每一句但没改变任何人心";或想检验别人一篇说服力爆棚的文章。

**原理**(第十八、十九章):
- "判断是通过证据考察和仔细推理得出的结论。……不像感觉，判断不是自发和无意识的。"
- 评价证据=提恰当问题:ch6 的11类问题包+总闸"相关吗"。
- 逐句编号提问法:先做准确总结(ch17六步),再把总结逐句编号逐条问——三好处:防第一印象、逐部分评价、提供组织结构(示范:对卜洛泽7点回答的逐条分析)。
- 六种重要区分(与第二篇错误论互为镜像):人与思想/所说与如何说/动机与对错/个人与群体/偏好与判断/熟知性与正确性。
- 判断表达六指南:平衡观点(拉什迪例、自尊例)/处理可能性("无论何时当你不能达成确定性时，就集中关注可能性")/主语适当具体/谓语准确("上帝死了"的8种读法)/包括限定语/避免夸大(宁低估不高估)。
- 说服定义:让未持立场者倾向同意,让反对者**被激励重新考虑**——不是击败。"论证的目的不是击败他人，而是通过观点的交流发现真理的全部复杂性。"
- 说服11原则(浓缩):尊重受众(用因素清单解释分歧,而非声明尊重)/理解读者(情况1、2、3;对方**最有影响力的错误**才值得最大火力)/从共同立场开场/积极态度(建构而非摧毁)/让人理解论证(不夸大分歧;强陈述改有保留陈述)/承认对方有道理(没有一方拥有全部真理)/不忽视相关事实/不用论证压倒读者(禁"我证明了/无可反驳/理性的人")/集中于最可能说服**此**读者的论证(参照框架:道德宗教/政治实践/哲学)/决不用自己认为不合理的论证/容留时间(求"最终"生效而非当下)。
- 正反对照教材:餐厅投诉信(违规标注版 vs 预先考虑读者反应版)——全书唯一完整改写演示。

**用法步骤**:
1. 下判断前:六区分逐个过一遍(尤其"偏好 vs 判断"——偏好不必辩论,判断必须可辩)。
2. 对材料做六步总结→逐句编号提问→每问给出采纳/拒绝/存疑。
3. 表达自检六指南:平衡?可能性语言?主语具体?谓语无歧义?有无限定语?夸大否?
4. 写说服文本前:写出读者的共同立场+他最有影响力的错误+准备承认对方哪一点有道理。
5. 用11条自查清单过稿;删掉任何自己都认为不合理的论证(第10条是一票否决)。
6. 发出后容留时间,不追击"你为什么不立刻同意"。

**边界**:
- 说服≠操纵:"真诚和尊重事实是作者最重要的品格。没有这些品格，就没有真正的说服，而只是巧妙的表述。"
- 集中火力于最可能起作用的论证≠只挑软柿子:仍需不忽视相关事实(第7条)。
- 推迟共识≠放弃立场;宁低估不高估≠含糊其辞到不可检验。

**出处**:第三篇·第十八章《形成判断》、第十九章《说服他人》(notes/ch18、ch19)
