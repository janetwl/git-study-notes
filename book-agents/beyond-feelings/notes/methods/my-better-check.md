# 方法卡 · "我的更好"监控(元错误解毒)

**何时使用**:这是全书的元错误检查,凡遇下列信号优先调用:用户贬损他人所有物/成就/思想("我这行才是正统")、对群体外的人秒下判断、同一行为换阵营就给不同评价、用"他们是那样的人"解释一切。

**原理**(第八章;第十三章定为错误组合的总起点):
- "我的更好"思维=**跳过评价,理所当然地认为自己(及所属)的最好**;任其不受制止,它就可能扭曲感知、腐蚀判断。
- 它有三层递进:所有物→成就→思想信仰(越往里越隐蔽、越顽固)。
- 演化链:自我中心(self-centered)→自我思维(self-thinking)→自说自话(EgoSpeak,"通过只谈论我们想谈的事情，一点也不关心他人想谈的事情来提升我们自我的艺术")。
- 族群中心两条判定信念:本群体根本优于他群+他群动机可疑;配套机制:双重怀疑标准、无中间地带、负面老套成见、"瞬间诊断"的替罪羊机制(哈克贝里·费恩四事实案例)。
- 切斯特顿定律:越在乎,越夸大。

**用法步骤**:
1. 盯**感觉迹象**:对某主张感到"特别顺耳"→可能正秒接受;感到"特别刺耳"→可能正秒抨击。
2. 盯**思想迹象**:出现"专家与我的观点一致""分析证据是浪费时间""不可容忍,因为它质疑我既有信念"任一,即报警。
3. "公平头脑"强制复评:把己方与对方主张**调换署名**再评一遍——同内容换标签后评价变了,就是"我的更好"在运作。
4. 溯源自问:这个"更好"感是评价后的结论,还是出生地/群体归属的默认出厂设置(接 ch1 影响通道)?
5. 界线声明(防矫枉过正):"评价之后判定自己的最好"完全合法;被禁止的是**放弃评价直接宣布最好**。

**边界**:
- 解毒针对"默认判定",不是要求自我贬低或价值虚无。
- 它常与反对变化偏见、偏见选证组合发作(ch13 链条)——发现它时顺链检查,见 error-consultation 卡。

**出处**:第二篇·第八章《基本问题:"我的更好"》(notes/ch08)
