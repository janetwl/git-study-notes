# 方法卡 · 观察→选题→探究(策略前半程流水线)

**何时使用**:用户要分析一个议题、写点东西、做个研究,或抱怨"想研究的东西太多/结论总被资料带着走"。也用于:用户对某人/某群体下判断却几乎没观察过(观察三问缺证据)。

**原理**(第十五至十七章,第三篇前半):
- 观察是思维的进料口:"清晰而合理的思维经常取决于只有经过仔细观察才可揭示的微妙细节。"所看所听与实情存在差距→感知不完全不准确,后面全歪。
- 观察人的三线索:说什么+说的**方式**+因疏忽**未说**的事;侦探-出庭律师类比。
- 洞见要降格为假说再检验(莫诺案例;显式回指第十章事后归因)。
- 选题:"少是多"——"目的在于深度而不是广度";宽议题=过度简单化的温床(限缩四收益:重点明确/能力内可掌控/研究有序/减少过度简单化)。
- 探究两分:探究**事实** vs 探究**观点**(有见识观点的获取,接 ch5);信息来源按阶梯走:自身经验→综合/专业百科全书→年鉴→传记/语言词典→期刊索引→图书馆与图书管理员→电脑数据库(infoTrak/PsycINFO/PubMed等)→因特网。
- 因特网三策略:搜索引擎(用搜索词宽度调结果量)/开发资源清单/评价来源(域名后缀 .gov/.edu/.com 与创建人议程;防恶作剧站)。
- 停止探究的红线:"对批判性思考的最大挑战之一就是当你发现一位知识渊博之士支持你的偏见时，让你停止探究的那种诱惑。"
- 充分性三档(承接第六章):确定性/证据优势/暂缓——"克制是批判性思考者的重要特征。"

**用法步骤**:
1. 补观察:让用户先讲"你实际看到/听到了什么"(三线索逐条过);说不出一条原始观察的,判断为二手印象。每日10-15分钟反思三问:它意味着什么?与什么关联?如何利用?
2. 限缩议题三步:列出该议题的所有方面(通常十几个,样本表见 ch16:色情文艺7方面/拳击6方面/青少年犯罪8方面)→按**兴趣×时机目的×时间篇幅**选1-2个→写成**落笔的聚焦问题**(防止做着做着跑偏)。
3. 按阶梯检索:从背景资料到专业数据库逐级走;网络材料跑"三策略"评估(谁建站、议程是什么)。
4. 处理长篇材料六步:确定关键断言→找结论→圈修饰词→查证据→看条件从句→写准确总结。
5. 达到三档之一才停;没到就继续,或明确标注"暂缓判断"。

**边界**:
- 考察两方面≠两方面同等有优点(对称收集不等于对称采信)。
- 第一直觉/洞见先当假说,不许直接上岗。
- 议题太大不是 ambition,是过度简单化的邀请函。
- 原书信息阶梯的数据库/URL 有年代痕迹(PsycLIT 等),思想框架仍可用,工具名按现状替换(此句为使用提示,非书中原文)。

**出处**:第三篇·第十五章《敏锐地观察》、第十六章《选择一个议题》、第十七章《进行探究》(notes/ch15、ch16、ch17)
