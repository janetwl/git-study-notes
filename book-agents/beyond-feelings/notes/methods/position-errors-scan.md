# 方法卡 · 立场错误七扫描(思维起点的歪镜片)

**何时使用**:用户观点的**出发点**可疑——只看到一个角度、有大量"理所当然"、非黑即白、"大家都"、"永远不可能有例外"、"各人有各人的真理"、或单纯因为"变了"就支持/反对。

**原理**(第九章):立场错误是"严重扭曲的镜片",七个:
1. 视角匮乏(邓克尔:思维贫乏的主要特征)——只用单一镜头看问题。
2. 无根据的假定——"假定是仅仅认为理所当然而非经过理性思考提出来的看法",书中列14条常见名录。
3. 要么/要么观念——把光谱压成两极。
4. 盲目遵从——Asch 线段实验:5人中仅1人敢说出眼睛看得出的事实。
5. 绝对主义——要求必有无例外的规则(交小刀被开除学生案)。
6. 相对主义——"真理是创造不是发现",三重自毁:摧毁批判思考、道德言说、法律(与绝对主义恰好构成一对双生子)。
7. 支持/反对变化的偏见——"你支持还是反对变化？唯一合理的答案是：'这取决于变化是什么？'"

**用法步骤**:
1. 镜头数一数:这个问题还有谁的角度(学科/立场/时代)没进来?
2. 挖假定:像挖隐蔽前提一样读字里行间,把"认为理所当然"的断言列出来,逐条问有无根据(对照14条名录:感觉可信/广泛报道为真/有理由即已推论/确信构成证据/熟知更有根据/时间在后即因果/多数人正确/现在是即应当是/变化总更好/表象可信/脑中想法是自己的且值得护卫/越确信越有效/发现错误即反驳)。
3. 对两极表述补写"既/又"选项与中间地带(书名对立例、福利改革、教育补贴券、男孩落后四案例是模板)。
4. 遵从检查:先区分可取遵从(安全惯例、模仿榜样)与盲目遵从;后者只问"合理正确与否",不问信的人多少。
5. 对主义双头:让用户的立场"自洽地应用于日常生活"——绝对主义过不了例外检验,相对主义过不了"批判/道德/法律"三重自毁(割礼、种族灭绝反例)。
6. 变化议题:把"新=好/旧=好"的标签撕掉,只评变化**内容**;警惕改革者变保守者(弗洛伊德→霍妮)。

**边界**:
- 相信绝对之物≠犯了绝对主义错误;界线在"是否要求无例外规则并拒绝检验"。
- 视角匮乏的根因是学科专门化+知识爆炸,不是道德缺陷——指出即可,别上价值。

**出处**:第二篇·第九章《立场的错误》(notes/ch09;"视角匮乏"节系2006版新增,不在原"六个"名录内)
