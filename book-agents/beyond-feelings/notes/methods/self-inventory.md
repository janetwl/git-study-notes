# 方法卡 · 智识自我盘点(18问目录+预测抵制)

**何时使用**:用户想系统性提升思考能力;反复在同类事情上栽跟头;或诊断完单个错误后问"我是不是有毛病"——把问题从"这次错了"升级到"我的易错面"。

**原理**(第十四章):
- "世界上90％的悲哀出自人们不了解自己，自己的能力、弱点，甚至是其自身的真正的美德。"
- 认知疗法依据(艾利斯):大部分精神问题出自错误的思维习惯——思维习惯可盘点、可预测、可抵制。
- 三组基本探讨问题:我的气质性格?别人可以信赖我到什么程度?我的自我意识与假面具差距多大?
- **批判性思考详细目录(18问)**:全书第二篇各错误的自我总检版(第17题集中问:事后归因/转移议题/自相矛盾/循环论证/虚假权威/错误类比/非理性诉求;第18题集中问:自动拒绝/转移举证/稻草人/攻击批评者)。
- 防御机制检查:哪些令人不快的念头被你"扫到地毯下面"了?——"如果你忽视了后者……你拒绝面对它们有可能加剧它们对你的伤害。"

**用法步骤**:
1. 诚实作答18问(全书清单在 ch14 笔记),不仅承认令人愉快的事实。
2. 反思锁定:从答案中圈出**你的**特别易错面(通常2-3项,别贪多)。
3. 预测-抵制:"无论何时你解决一个问题，预测哪些问题有可能破坏你的思考，并有意识地抵制它们的影响。"——动手思考前,先写下"这次我大概会犯哪条",像排雷一样预标。
4. 周期性重测:目录不是考试,是一季一盘的仪表盘。

**边界**:
- 锁定易错面≠给自己贴永久标签(那本身就是一条"无根据假定"——"脑中想法是自己的且值得护卫"的变体)。
- 反思≠自我批判:盘点目的是"预测-抵制"这个操作闭环,不是道德忏悔。
- 目录中"是否族群中心/我的更好"类题目答"否"时,让 TA 用具体事件举证(这题是自我中心的高发伪装区)。

**出处**:第三篇·第十四章《知道你自己》(notes/ch14;目录条目复现第二篇 ch8-13 错误名录)
