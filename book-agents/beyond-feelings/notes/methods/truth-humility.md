# 方法卡 · 真理观与认知谦逊

**何时使用**:用户说"没有绝对真理/每个人有自己的真理""这事谁也说不清,两边都对";或宣称"我知道X"却说不出如何得知;或在信念与事实之间打滑。

**原理**(第三、四章):
- 真理符合论:信念和断言与现实相符即为真,不符即为假;真理是被**发现**的,不是被创造的。我们创造的是**信念**——"信以为真但很可能是虚假的想法"。
- 人的认知容易出错有五环:童年依赖(所信即所见)、不完善的感知、不完善的记忆、有缺陷的信息、专家群体也会出错。
- 关键区分:**尚未掌握 ≠ 没有真理 ≠ 双方一样正确**(UFO、托马斯听证案例)。争论多年无定论不等于怎么说都对。
- 认知的必要条件:答对+认识到自己拥有+通常能说出如何得知(玛丽/南希案例——"确信感≠知识")。
- 两大障碍:设定(把既定框架当现实)与猜想(把猜测当定论)。

**用法步骤**:
1. 遇到主张先问:这是与现实的相符陈述,还是我的"信念跳跃"(阿德勒语)?
2. 认知体检:"我和其他人认为我们知道的事情有可能在事实上并非如此吗?"——用第四章8条"共同知识"证伪例(性别抚育/发泄愤怒/清教徒形象等)校准对自己的常识的信心。
3. **谨慎断言三级用语**:把过强的"我知道"降档——"可能/大概"(证据不足)→"我认为"(有倾向但开放)→"我知道"(满足认知三条件)。负责任的说法模板:"根据证据,我们认为最可能……"。
4. 对"两边都对"僵局:检查是证据真不对称,还是自己/对方提前缴械。

**边界**:
- 承认无知≠无主见、≠不探究(书中明言"不等于没有立场");谦逊是"承认无知是通往知识关键的第一步"。
- "不能证明的≠不真实"(信仰一节),谦逊是双向的:不宣称绝对,也不滑向相对主义(相对主义的归谬见 position-errors-scan 卡)。
- "摆脱自负。因为任何人都不可能开始学习他认为自己早已知道的事。"

**出处**:第一篇·第三章《真理是什么?》、第四章《认知意味着什么?》(notes/ch03、ch04)
