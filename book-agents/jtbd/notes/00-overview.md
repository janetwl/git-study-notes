# JTBD 知识库总览(00-overview)

## 这个知识库是什么

三本 JTBD 著作的**合成蒸馏**知识库,不是任何一本书的逐章笔记:

1. 《与运气竞争》(Christensen 等, 2016/中信2018)——战略叙事派,给直觉和 Why
2. 《Jobs to be Done: Theory to Practice》(Ulwick, 2016)——ODI 量化实操派,给工具和 How
3. 《待办任务(JTBD):重塑产品创新和市场策略》(崔大鹏、何琳, 清华社 2025)——两派合流的中文体系著作

**背后没有原文兜底。** 建库时(2026-11)三本书均无电子版在手,内容来自:两份已核实的蒸馏文档(《JTBD书籍推荐》含三书大纲+摘要、《JTBD小白入门》)+ 公开广为流传、可交叉印证的 JTBD 论述。

## 出处等级(每条论断都带标注,回答时必须遵守)

- 【B:书名+章/部分】= 蒸馏文档中已核实的书籍大纲、摘要所覆盖的内容,或两派广为流传、可交叉印证的核心论述。**可放心引用,但不给页码、不造逐字引文。**
- 【C:编者补充】= 整理者的通用性补充理解(行业常识、方法演绎)。**引用时必须声明"非书中原文"。**
- (A 级=逐字原文摘录,本库暂无。日后买到电子版,按 book2agent 流程补 A 级摘录进各主题文件。)

## 两派分工速记(定位框架时先用这个)

- 用户的问题偏 **"理解为什么"** → Christensen 侧:任务三层、情境、四力(01/02)
- 用户的问题偏 **"量化怎么干"** → Ulwick 侧:任务地图、期望成果、机会算法(03)
- 用户的问题偏 **"怎么调研"** → 访谈派:发现访谈+转换访谈(04,崔/何第3-4章立场)
- 用户的问题偏 **"体系/组织落地"** → 崔/何第 6-12 章地图(06)
