# 进步四力模型(02)

## 模型本体

用户从现状转向新方案(或反之)时,有四股力量同时作用。【B:《与运气竞争》"进步力量"四力模型;《待办任务》第4章转换访谈采用同一模型】

**推力(促变):**
1. 对现状的不满/痛点(life gets in the way)
2. 新方案的吸引力( promises 新奇与好处)

**阻力(维持现状):**
3. 对切换的焦虑(怕踩坑、怕不会用、怕选错)
4. 旧习惯的惯性(已经熟练、沉没成本、"凑合用")

**关键诊断律:新产品扑街,多半只加了推力、没减阻力;两股力各自独立,吸引力再大也压不住焦虑。【B:《与运气竞争》要义,C 级展开】**

## 诊断提问(把四力变成可问的问题)

对一次真实的"换/不换"决策逐一拷问:【C:由模型演绎成的访谈提问,供方法卡直接使用】

1. 推力①:你是什么时候**第一次**对现在用的东西感到不对劲的?那个瞬间发生了什么?
2. 推力②:新方案里最吸引你的是哪一个具体点?它承诺帮你办成什么事?
3. 阻力③:决定前你犹豫过什么?最怕发生的坏事是什么?谁劝过你别换?
4. 阻力④:旧方案哪个部分你其实舍不得/已经习惯了?换的成本(钱、学习、迁移数据)是什么?

## 典型误用与边界

- 误用一:把四力当成"打分数"的问卷(它本质是**访谈分析工具**,靠时间线叙事提取,不靠 Likert 量表)。【C,与 04 访谈方法一致】
- 误用二:只在"获客"用它,不在"流失复盘"用它——用户弃用你,多半是焦虑+惯性赢了,而不是功能输了。【B:《与运气竞争》应用要义】
- 适用:任何"转变决策"(换供应商、订阅、转学、用不用新功能);不适用:纯冲动/无替代可选的一次性低价购买(四力介入空间小)。【C】
