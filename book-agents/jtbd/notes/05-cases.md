# 已核实案例库(05)

## 1. 奶昔(两派共同的原点案例)

快餐店按传统方法(问现有顾客要更浓还是更甜)改版,销量不动。Christensen 团队换问法:"顾客雇这杯奶昔,是来办什么事的?"【B:《与运气竞争》第1章"奶昔的两难"】

发现两个雇佣场景:
- **早 8-9 点独自开车的通勤者**:任务="让通勤路不无聊+扛饿到中午"。奶昔赢了香蕉/贝果/咖啡:吸管吸 20 分钟、不弄脏衣服、单手可得。竞争对手是**无聊**。
- **下午带孩子的几位父亲**:任务="给孩子买点东西又不显得不健康"。完全不同的任务,不同的对手(糖果)。
【B:蒸馏文档核实过的案例细节;更细的数据点(如浓稠度改版)本库未记录,勿编】

教学价值:同一种产品×两种任务×两种竞争 = 按"人群"卖 与 按"任务+情境"卖的认知层级差别。【C】

## 2. Swiffer / Clorox(过满足之外找成果)

"快速擦净厨房地面油污"这一功能任务被**过度满足**(抹布+拖把足够干净),机会反而藏在别的成果层——"不想弯腰蹲地擦"。催生 Swiffer。【B:《JTBD小白入门》引 Clorox/Swiffer 案;《Theory to Practice》应用篇含 Clorox 案例——两源交叉印证;细节以原书为准】

## 3. Netflix vs Fortnite(竞争由任务定义)

Netflix 自我定位的任务="帮我在工作一天后放松",所以公开承认的对手包括 Fortnite 和"睡眠"。【B:广为流传的 Netflix 高管言论,两派材料均引为案例】

推论:定义竞争前先写下任务,竞对清单会跳出你的品类。【C】
