# 方法卡:四力诊断

**何时用**:回答"为什么不买/为什么流失/为什么推不动"——把模糊的"市场不行"拆成四股可命名的力。

## 操作步骤

1. 锁定**一次真实转变**(或该转变的缺席):某用户换成了 X,或始终没换。访谈取原始叙述(配 `switch-interview.md`)。
2. 把叙述材料填入四格:

| | 内容(原始语录) | 强度判断 |
|---|---|---|
| 推力①对现状不满 | 触发时刻发生了什么 | |
| 推力②新方案吸引 | 最吸引的具体一点 | |
| 阻力③切换焦虑 | 犹豫/害怕/谁反对 | |
| 阻力④旧惯性 | 舍不得的部分/切换成本 | |

3. 定位**决定性阻力**:没成交/流失的那次,③和④哪股更强?原话是哪句?
4. 出方子(诊断律:只加推力必扑街,先减阻力):
   - 治焦虑③:免费试用/迁移协助/示范视频/退路承诺/第三方背书
   - 治惯性④:降低切换动作数(一键导入)、保留旧习惯的熟悉形状、给旧方案一个"毕业仪式"
5. 72 小时最小验证:挑一个阻力,设计一个专门消它的小动作(文案改一句/加一个引导步骤),投放后看该环节转化。

## 适用/不适用

- 适用:一切"转变决策"(换供应商、订阅、新功能采纳、学生转课程)。
- 慎用:无替代可选的一次性低价冲动购买(四力介入空间小)。【C】
