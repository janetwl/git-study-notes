# 方法卡:期望成果陈述 + 机会打分表

**何时用**:任务地图完成后,把"躲开的东西"炼成可量化、可排序的机会。

## 成果陈述公式

`在(某执行步骤)时,尽量减少(某个不想要的结果)的概率/发生率`

- 一条成果只挂**一个步骤**、**一个不想要的结果**。
- 不想要的结果必须**可观察**(中断、超时、返工、被孩子拒绝、被家长质疑),不能是感受词(不爽、麻烦、不好看——那是原材料,继续追问"不爽的具体瞬间是什么")。

示例:"备份照片时,尽量减少备份中断的概率"(库内核实例)

## 打分与机会算法

请 10~30 个目标用户对每条成果打两分(1~10):重要性 I、现有方案满足度 S。

> **机会分 = I + max(I − S, 0)**

- ≥15:优先进入创意/路线图(欠满足)
- I 高 S 也高:过满足——做减法或换交付方式,别加功能
- I 低:搁置

## 打分表模板

| 编号 | 阶段 | 期望成果陈述 | I | S | 机会分 | 判读 |
|---|---|---|---|---|---|---|
| O-01 | 确认 | 在选择课程时,尽量减少孩子第一次课就抗拒的概率 | | | | |

## 纪律

- 打分对象必须是**做这个任务的人或为其买单的人**(奶昔案例:早晨买单人自己喝,下午父亲为孩子买——分开打)。
- 分数冲突大(同一成果 I 方差高)= 你把两个任务混进了一个地图,回去分层。【C】
