# 《通往财富自由之路》(李笑来, 2016-2017 专栏) · 全书地图

## 一句话核心
**财富自由不是"有很多钱"，而是"再也不用为了满足生活必需而出售自己的时间"；通往它的真正路径是先重造心智操作系统（用清晰概念+价值观排序"什么更重要"驱动注意力），再把同一份时间卖出更多次/买别人的时间（时间生意三级台阶），并以定投式纪律让复利在长期里兑现——而这一切只有"践行"能兑现，人至"践"则无敌。**

## 全书逻辑流（五段）
1. **重定义目标**（ch00-02）：先把"财富自由""出售时间""注意力"三个概念定义清楚——清晰且正确的概念是一切思考的基石。注意力>时间>金钱。
2. **心智操作系统**（ch03-18）：安全感是枷锁、活在未来、贵人原则、落后刻度、多维竞争；核心是元认知能力（对思考的思考）及其三条训练管道，外加戒抱怨、看见他人的好、"正确×不被认同"的价值公式。操作系统双核=概念+价值观。
3. **投资避险纪律**（ch19-30、45-46）：刚需可塑造→投资的刚需是避险；资本三要素（智慧>时限>金额）、给钱"判无期徒刑"、永远不要押上全部、预测是幻觉、GAFATA+定投、"你越弱你的长期越长"（72法则）、趋势要两个周期才现形、左侧右侧的镜像世界。
4. **时间生意与成长率**（ch31-44）：三种个人商业模式（单份卖→卖多次→买时间），写作是复数销售；价格由需求决定；"聪明"重定义为清晰准确必要的概念；成长率是一切生意的核心指标；知识=能改进决策的信息；智商=可升级的操作系统；速成=快速入门（MAKE），重复+希望是从天才到精通的唯一通路；学习能力的第三境界（无人可教处自学）是作弊器。
5. **收官：原则与践行**（ch43、47-52）："什么更重要/什么最重要"一把刀解决所有选择；把价值观固化成原则清单并复盘；提出高质量问题=解决问题；执行力=内化+生产（三重大脑/柏拉图战车），终极出路是进化成"另一个物种"——财富自由只是里程碑。

- 出处一律用"第 NN 辑（chNN）+ 小节/日期"，无页码。
- quotes.md 是唯一逐字引用仓库；各篇笔记引号内均已机器校验为原文逐字。
- 书内自我引用频繁（ch24/28/41 等大量回指前文）——跨辑回答时可顺笔记里的"回指"追查。
