# ch13 · "错过"（2016-10-28）
出处：专栏第 13 篇《"错过"★》。关键词：错过、升级。
## 定位
用作者亲身"生生错过一辈子"的经历(庄轶白板两小时)解剖最隐蔽的失败模式:重要观念伪装成"跟你没关系"而被错过。它给 ch09-10 的元认知训练补上"为什么学了不用"的心理根源,并首次系统论证"只字不差地阅读、好书读很多遍"的必要性;与 ch14"自证预言"直接呼应。
## 核心论点（方法论优先）
- 亲历案例(完整保留细节):2007 年夏,作者即将离开新东方,一位姑娘递名片请他见朋友"庄轶"(某知名创投创始合伙人,真名已隐去)。庄轶被斯坦福邀读 MBA,坚持要考 TOEFL/GMAT 才"厚道",助理试听两个老师各一节课后选了作者。两三个月里每周见一两次,作者把两个考试体系讲了一遍。庄轶出发去旧金山前,站在苏州街大河庄院一间屋子的白板前,写满整个白板、擦掉、再写、又写满,讲了整整两个半小时创业方法——基本等于作者在新东方讲一整节课的时间。
- 见面细节:作者一向习惯不打探别人的事;那两三个月里庄轶给他留下深刻印象——一个飞来飞去、动不动一天只睡三五个小时的人,竟然可以在机场完成作业,再专门腾出时间来找他过一遍;"我喜欢一切做事足够狠的人"。
- 错过的事实:两年后庄轶从斯坦福回来,作者并没有太多具体变化——他走之前作者和前新东方同事熊莹搞的出国留学咨询公司,回来时还在做,没什么增长,"确实赚钱，但是那种在我今天眼里完全不是“创业”，而仅仅是“生意而已”的东西"。
- 噩梦惊醒时刻:2013 年下半年作者开始做天使投资,一路磕磕碰碰;2014 年年初飞硅谷的飞机上突然想起几年前那个白板前的下午——尝试若干次仍无法清楚回忆当时讲述的内容,只记得确实有这么回事、有大概印象,细节全然模糊,跟大梦初醒无法追回梦中细节一模一样。作者反应过来:当时庄轶所讲的一切,我其实根本就一点儿都没听进去。
- 期间的联络并没有救他:这期间每年至少见面闲聊一次(作者有个习惯:主动联系那些若不联系就可能断了联系的朋友),还通过他认识了朱敏先生(朱敏为《把时间当作朋友》写了序)——这一切交往并没有把作者从"毫无知觉"中拉出来,他仍按原来的思路行事,对创业这事儿全无感悟。
- 普遍化:很多读者说"写得太好了,说得太对了",过段时间再回想,和作者一样其实没听进去。阅读时的快感会让人产生错觉,认为自己看懂了、生活就会自动变得不一样;但那只是幻觉——如果你回想不出当初到底读到了什么,这些文字对你的意义并不大,最终你只会在走过弯路之后才想起曾经读到过类似的提醒。
- 错过的机制(核心论点):作者在与创业者沟通中认出同样的反应:"我觉得你说的都对,但,好像跟我没有太多的关系……毕竟,我不是你,你也不是我,你能做的事儿,我不一定能做……我还是安心做好我能做的事情罢……"——有的时候错过只是因为觉得这件事和自己没关系;有的时候只是为了逃避困难而试着说服自己这件事和自己没关系。
- 关键推理(判断标准):有些观念,你觉得跟自己有关,它也不一定会起作用;但反过来,若是你觉得与自己无关,那么它一定不会起作用。仅仅"以为某些观念于己无关",就可能让一个人永远生活在另外一个"自洽的世界里"。
- 破解·操作一:主动吸收那个观念,按照那个观念去做,就"事实上有关系"了。
- 破解·操作二:做不好不要紧,没人一开始就做得好,于是拼命去做就是了;刚开始无法很熟练地按照那些观念思考也没关系,反复琢磨、反复尝试,自然而然就开始深入。
- 总诀:做就要使劲地做,想就要深刻地想——否则就跟你实际上完全没有关系。
- 事后回看的反转:得出"与我无关是错觉"的结论之后,好像有一股很神奇的力量在起作用,作者渐渐能清楚回忆出当年庄轶站在白板前讲的究竟是什么——基本上就是他现在经常给别人讲的观念:怎样在改变行业的过程中找到巨大价值,怎样才能锁定最长的赛道,怎样才能迅速增长;甚至有点分不清这些是自己挣扎学来的,还是许多年前庄轶"种了一颗种子"最终竟然生根发芽了。
- 第二个障碍·过度预期:你没去做不是因为真的做不好,只是你"以为"自己做不好,更准确说是你以为自己"永远"做不好;根因是目标定得太高。"理想丰满,现实骨感"的障碍可能是自己设置的。开始的时候不妨不考虑有没有关系、能不能做好,直接去做;有了第一步,自然知道下一步定什么目标合适。
- 阅读方法论(操作标准):这正是强调"我的专栏,建议读者只字不差地阅读"的原因——这个专栏是关于观念升级的,不是胡乱写写随便看看、娱乐消遣的东西;不仅要只字不差地阅读,还要反复阅读,因为最底层的观念常常披着"简单"的伪装,乃至于大多数人觉得无所谓、觉得自己已经理解。
- 阅读的最深要求:先假定每个观念都跟你有巨大的关系,调动所有感官为自己创造"带入感",去琢磨、去研究、去想象:这个观念若是被自己吸收之后,自己应该变成什么样子?
- 【思考】区的政策提醒:国家政策(是政策,不是政治)与个体财富积累有很多联系,甚至经常能够完全改变个体财富积累的路径;为了你自己,你得关心那些政策、认真理解那些政策、深入思考每个可能性与自己的联系及影响,进而做出自己必要的改变(并建议写在只给自己看的本子里)。
- 视角切换即学习:大多数人一直把自己当学生,从没从老师角度考虑问题;"教是最好的学习方法"践行者是少数。创业者若真听进投资者的话、站投资者角度思考,事业大有帮助。成绩不错的学生的共同特点:听得进去老师的话。
- 反转细节:得出"与我无关是错觉"的结论后,"好像有一股很神奇的力量在起作用",作者渐渐能清楚回忆出庄轶当年所讲——基本上就是他现在常给别人讲的观念:怎样在改变行业的过程中找到巨大价值、怎样锁定最长的赛道、怎样迅速增长;甚至分不清这些是自己挣扎学来的,还是当年庄轶"种了一颗种子"生根发芽。
- 运气自觉:人生难得第二次机会,作者两次"生生错过"都竟然失而复得,自认运气格外好;若运气一般,完全可能还在过许多年前的日子——不会有现在的惊恐、后怕和对好运的珍惜。
- 脊背发凉的事实:六七年的时间,就那么过去了。想想这真的很可怕。
- 总括句:有些观念真的很重要,但它们要么太简单乃至于被人们轻视,要么太过违背直觉乃至于无法相信。
- 附加区要点:面对新知识新观念,不要让"与我无关"的想法先占据大脑,不妨主动吸收、按那个观点做一下;文章只能提醒你思维漏洞的存在,不去修补就永远只是知道漏洞而已;不能只停留在后悔层面,要总结过去经验、重点分析做错的原因、逐一改正;"这事和我没关系,不要多想"是可怕的自我暗示,掩耳盗铃貌似自我保护,实际把自己推向更危险的境地——那些你以为没关系的,多半有一天会以你再也无法无视的形式重新出现;看到不错的材料,尽量放进脑子或花时间记录,花费力气让它与其他知识产生联系,才能真正印在脑子里。

## 辅导提示
- 用户"道理我都懂,就是没改变" → 本篇:懂而不做,多半是你悄悄假定"这跟我没关系";先假定每个观念与你有巨大关系,制造带入感再读一遍。
- 用户"我这种情况特殊,不适合我" → 庄轶案例镜像:现在的创业者对作者的反应正是当年作者对庄轶的反应;"你能做的事我不一定能做"是逃避困难的自我说服。
- 用户"目标太高,一直不敢开始" → 你以为自己"永远"做不好=过度预期;开始时候不考虑能不能做好,直接去做,有了第一步自然知道下一步目标怎么定。
- 用户"书读了就忘" → 回想不出读到了什么=没读进去;只字不差地读、反复读,并尝试复述/教别人(教是最好的学习方法)。
- 用户"错过某机会多年懊悔" → 作者也错过六七两载;重点是别停留在后悔,总结做错原因并逐一改正(附加区)。
