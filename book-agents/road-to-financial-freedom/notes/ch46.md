# ch46 · 投资的世界"镜像世界"(20170616)
出处:专栏第 46 篇《46.20170616投资的世界"镜像世界"★》。关键词:运气、镜像世界、左侧、右侧

## 定位
紧承 ch45 周期与趋势,本篇给投资世界立一个总纲:成功=技能+运气,按运气权重把人类活动排成光谱,于是世界被切成左右两侧的"镜像世界"。它是全书最重要的世界观切换点之一——大量在左侧(学习、工作)所向披靡的聪明人,带着左侧经验冲进右侧(投资)而折戟沉沙。此后"别押上全部""什么都不做""定投"等右侧策略都从这里获得依据。

## 核心论点(方法论优先)
- 投资是一路成长的你终将必然闯进去的领域,甚至越早进入越好;没吃过猪肉也要看过猪跑,暂时没能力进入,先有概念上的了解也是必要的。
- "等我有钱了,我就……"的人大部分不太可能有钱,即便有了也多半无法正确使用:金钱只是很小的因素,真正重要的是使用金钱的智慧,其积累比金钱积累难得多。应该庆幸现在还没钱,趁有时间先打磨支配金钱的能力,等真有钱时才不产生重大损失。
- 镜像世界:不同物种常常活在不同的世界里,尽管那世界看起来一模一样——一切都是反过来的。
- 核心公式:成功 = 技能 + 运气。人们从事的活动按运气权重 0 至 100% 排列:象棋、围棋技能占 100%,没有运气空间;抛硬币式纯赌博运气占 100%,没有技能空间;中间是技能与运气成分不同的光谱(打篮球技能很重要,但已投中的球可能在篮筐里弹几下出来)。
- 投资活动更靠近右端:运气权重很高,技能再强也有运气不好的时候,而且运气不好的时候可能更多。
- 资源配置原则:某件事更靠运气,只要投入的时间精力与之匹配,最终因"倒霉"没获理想成果也可以接受;反之,即便更多依赖技能的事,不顾一切押上全部,也可能因那微小的失败概率而损失全部——概率小并不代表它不会发生(呼应:投资的刚需是避险、永远不要押上全部)。
- 两侧策略不可互换:在左侧运用右侧的策略是不恰当的;在右侧运用左侧的策略甚至很可能干脆是致命的。绝大多数"聪明人"在投资领域损兵折将、尸骨无存的根本原因:积累了大量左侧经验所向披靡,冲进右侧却没看出这是镜像世界,处处优势变劣势,最后"死因不详"。
- 最明显例子是对努力勤奋的理解:左侧,努力勤奋是上等策略;右侧,努力勤奋事实上是无效策略,因为它对运气的影响可忽略不计。在投资的世界里赚钱不靠努力,"什么都不做"不仅是最重要的事情,还是最难做到的事情;这个道理只有做到一定地步才有机会深刻体会,在此之前无论多少人说明,你只能表面上理解,骨子里还是原来的物种("不明觉厉然并卵")。
- "什么都不做"的准确含义:所有投资里面需要做出的努力,其实都应该在投资之前做完;真正开始投资活动之后最佳策略是"什么都不做"。操作得越多,失误的可能性越大;如果一个投资项目需要你不停地努力操作,很可能从一开始就不应该进入。
- 讨论与众包:越往左不确定性越小,讨论容易、方向结果通常确定,讨论价值巨大;越往右不确定性越高,很难多方同时正确理解真相,更别提仅用语言这个模糊工具达成一致——所以在投资领域"众包"事实上并不靠谱,是左侧极其有效、右侧完全无效的策略。
- 向无投资经验者讲投资原则通常被认为是"不可能完成的任务",因为学习者暂时没办法有足够的"体验"支撑理解(如"少壮不努力,老大徒伤悲",元认知尚未开启,到伤悲阶段才反应过来,只剩悔恨)。而专栏读者不会太难,因为操作系统里已有基础概念:元认知能力、镜像世界、运气权重、左侧策略、右侧策略。
- 危险信号:随后的道理看起来直白简单,让你产生"这还用你告诉我?"的念头时,恰恰最危险——若元认知不提醒你,你会忘了这是镜像世界,你看到的可能是"长得一模一样,却事实上截然相反的东西"。
- 左右侧技能清单回顾:左侧(可控、践行就有收获)——多个维度打造竞争力、不光为老板打工更要为自己打工、锻炼元认知能力;右侧——抛弃对安全感的过分追求、努力活在未来、通过定投抵抗风险;而学习概率是客观了解运气的最佳途径。
- 左舵/右舵车类比:在中国习惯左舵,到欧洲满街右舵、靠左行驶,一眼明白左右之分,开始时却像"弱智"不断犯错差点出大车祸;投资领域不出事倒也罢了,出了事很可能性命攸关。
- 再提醒:在右侧世界里,哪怕一模一样的行为、方法、理论,很可能(也不一定)会有与它们在左侧世界里截然相反的结果、效率、或者作用。这也是为什么聪明人对一切问题的标准答案只有一个:"看情况"(具体情况具体分析);所有笨蛋都希望找到一条唯一真理适用于全人类、古今未来、所有领域——历史上从来没人成功,因为这追求本身就是基于懒惰的愚蠢。
- 要学的不仅是右侧世界,更是学会在两个世界自由穿梭:在左侧遵守左侧的规则、运用左侧的策略;在右侧遵守右侧的规则、运用右侧的策略。穿梭多了会解脱:并非所有"截然相反"都同样重要,最终只有少数必须 100% 重视;偶尔还会发现两边通用的原则,那是幸福感破门而入的感觉。
- 反向提醒:碰到"付出就有回报"的事情(运气因素非常少、投入相应精力时间就会有产出)要好好把握,这是为数不多能最大化工作效率的机会。
- 附加要点:把努力能够获得回报的事情交给自己,把需要依靠运气的部分交给时间;风险本身没有绝对大小,取决于你"赌注"的大小和"赌本"的大小;复习第 21、28、31 周文章。

## 辅导提示
- 用户用工作勤奋心态做投资(天天盯盘操作) → 用"什么都不做"框架:功课在投前做完,操作越多失误越多;需要不停操作的项目一开始就不该进。
- 用户(某领域高手)投资惨败想不通 → 镜像世界:左侧经验在右侧处处优势变劣势;先判断该活动在运气光谱的位置再选策略。
- 用户到处问"这只票能不能买/大家投票决定" → 右侧不确定性高,"众包"与语言讨论在右侧无效;只能自己研究、自己决定。
- 用户借钱 All in 看似高把握的机会 → 依赖技能的事押上全部也可能因微小失败概率损失全部;投资刚需是避险。
- 用户纠结该不该花钱买服务/省时 → 分辨这件事运气与技能占比,再决定赌注大小;碰到"付出就有回报"的事要死死抓住。
