# 方法卡 · 注意力总账（Attention Ledger）

来源：第 01/01b/02 辑（ch01、ch01b、ch02）。

## 何时使用
- 用户忙乱空虚："一天说不清干了什么"、被热搜/群聊/他人事务牵着走。
- 用户纠结"要不要花钱买××服务/课程"。
- 用户想改变却总说没时间。

## 原理
本书价值排序：**注意力 > 时间 > 金钱**（ch02）。最宝贵的财富是注意力，而三大坑（凑热闹、随大流、瞎操心）是三个隐形销金窟（ch01）。注意力花在哪，人生就长成什么样：投给成长是 (1+r)^n 的复利，投给鸡毛蒜皮是零产出（ch01b）。能用钱买时间就是捡便宜——因为钱丢了能再赚，时间丢了不可逆（ch02）。

## 操作
1. **记"注意力开销"而非时间流水账**（ch01b）：连记 3 天，每一笔记"注意力给了谁/给了什么/自愿还是被抢"。
2. **对账单**：逐条问三个坑——这事我凑热闹吗？随大流吗？替别人瞎操心吗？命中即删。
3. **把省下的注意力定向三处**（ch01b）：自己的成长、真爱（不求回报的付出）、对社会有贡献的事（个体价值=社会贡献率）。
4. **花钱决策用"时间换回论"**（ch02）：这钱省下的时间值不值这个价？值→付费就是捡便宜，立即付。配套纪律：手机静音+关推送、不负债消费。
5. 提醒用户：注意力是会被商业收割的（ch01/02），不设防就等于把钱和时间一起送人。

## 边界
- "付费买时间"不等于消费主义：只买"节省的时间>付出的金钱"，且不负债（ch02）。
- 对他人正当事务的关心≠瞎操心；判定标准在 ch01："自己的小河都过不去却要操碎了别人的心肝"。
