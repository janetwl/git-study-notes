# 方法卡 · 快速入门与长期精进（Fast Start, Long Repeat）

来源：第 40/41/43/44/52/13 辑。

## 何时使用
- 用户"怕学不会所以不敢开始"/完美主义拖延。
- 用户开始三天就放弃——多半没预估重复次数。
- 用户"看了很多没长进"——想到≠做到的断裂。
- 用户想学一个"没人能教"的新领域。

## 原理链
1. **速成的正名**（ch40）："快速成功"不可能，但"快速入门"绝对必要。用 **MAKE（最少必要知识，Minimum Necessary Knowledge）尽快开始、尽快度过**：接受一开始必然笨拙，把注意力放在"改进"而非"面子"上——"练习时丢的脸不可避免，因为没有人能够在开始的时候就做好任何事。但是因为怕丢脸而不练习，那么，随后每次需要用到相应技能的时候，其实也都是在丢脸，而且这种丢面子的次数上不封顶。"（ch40 原文）
2. **重复是从笨拙到熟练的唯一通路**（ch41）：人半途而废的主因=严重低估所需重复次数与任务复杂度；先估算"我要重复 100/1000 次"再开始，挫折感变预算内成本。支撑重复的是**希望**=相信明天因今天的努力更好——希望需要刻意守护（ch41/ch42）。
3. **想到≠学到≠做到**（ch43）：能变现的只有认知差异，而认知差异只能靠"行动中的思考"（践行）产生——人至"践"则无敌（ch43）。
4. **学习能力的三重境界**（ch44）：①有人手把手教 ②能看书自学 ③在完全没人可教、没书可照抄的领域自修成功——第三种是"作弊器"（作者以比特币与 Critical Thinking 自证）。
5. **执行力不是意志力问题**（ch52）：三重大脑/柏拉图战车——黑马（直觉）、白马（情绪）、骑手（理智）；执行力=把事情"内化"（重复+应用，情绪是理智的捷径、直觉是情绪的捷径）+持续"生产"，终极目标是把新技能内化到不需要说服自己。
6. **阅读接口**（ch13）：对重要观念默认"跟我有关"，只字不差地读、反复读、直接去做——"觉得无关就一定不起作用"是可怕的自证预言。

## 操作（启动一个新手艺的标准流程）
1. 写下要学的事→列出它的 MAKE：5 条以内"不知道就百分百用不了"的最小知识（ch40）。
2. 立刻用残缺技能做出一个最小真实产出（第一篇/第一单/第一次），主动去丢一次脸（ch40）。
3. 预估重复次数并写进日历（ch41）：入门级 ≈100 次？专业级 ≈1000 次？按每周频次给出结束日期。
4. 每周一次"践行检查"（ch43）：这周的行动产生了吗？行动中的思考写进复盘（ch10 反思管道）。
5. 无人可教时启动 ch44 三境界路线：找最近邻领域类比→拆最小实验→自己造教程（然后教=再学一遍）。
6. 中途动力衰减：检查是"重复次数超预期"（校准预算）还是"意义断供"（转 meaning-stack）还是"被比较劫持"（转 no-complain）。

## 边界
- MAKE 之后必须补全：快速入门≠停在入门（ch40 反复强调"尽快度过"，赖在入门区=另一种速成幻觉）。
- "重复"不等于无脑重复：每次带一个小改进才是内化（ch52）。
