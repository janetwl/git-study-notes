# 方法卡 · 万能钥匙（The Master Key）

来源：第 11 辑（ch11"万能钥匙"）。

## 何时使用
- 用户对着一个问题死磕：越焦虑越想，越想越焦虑。
- 用户"卡在原地"数月：方案比较不出结果。
- 用户问一个无解/错构的问题。

## 原理
本书点名的"万能钥匙"：**解决方案（钥匙）从来不在问题（锁头）本身里，把注意力从问题移开，去别处找**（ch11）。机制：问题在窄焦里只是墙，注意力撤回来放进更大的系统（生活整体/其他领域/时间线）后，钥匙才会显形（ch11；与元认知协同——移开注意力是有意识地移开）。专栏"不谈钱谈能力"就是这个原理的示范：总盯着钱的人赚不到钱（ch11）。

## 操作
1. 判定"死磕态"：用户描述里问题被重复 N 遍而信息量为零 → 启动本卡。
2. **主动换输入**：去做一件毫不相干但需要投入注意力的事（运动/读别的领域/见别的圈层的人）——不是逃避，是去钥匙可能的存放处巡逻。
3. 重构问题维度：把"如何解决 X"改写成"什么更重要，以至我可以绕过 X/让 X 消失"（与 os-upgrade 的一把刀互参）。
4. 记录"卡住时刻"：写下问题+当时情绪，24-72 小时后回看——多数钥匙在重读时浮现（ch11 强调记录）。
5. 若问题本质是资源不足：去 ch06"资本三要素"与 ch24"虚拟持股"——很多'解决不了'其实是'还没开始'。

## 边界
- 移开注意力 ≠ 拖延执行：已明确路径的事直接做（fast-start），本卡只治"想不出"不治"不想做"。
- 别把"去别处"变成消费/娱乐漂移——那三大坑（ch01）会没收你的注意力，移开要移向"有输入的事"。
