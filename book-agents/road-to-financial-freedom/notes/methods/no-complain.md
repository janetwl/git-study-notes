# 方法卡 · 戒抱怨与换眼光（No Complain / See the Good）

来源：第 15 辑（抱怨）+ 第 16 辑（看见别人的好）。

## 何时使用
- 用户习惯性诉苦、吐槽环境/公司/伴侣，问"我是不是该忍"。
- 用户在比较中失衡：嫉妒同行或鄙视同行。
- 教练识别"注意力被他人叙事绑架"的用户。

## 原理
抱怨是无能无奈的表现，且**会传染、会上瘾**；真正的害处是它让人"不由自主放弃挣扎"——把解决问题的注意力换成了情绪宣泄（ch15）。配套机制：多数人终生在"你不行/我行"与"你行/我不行"之间穿梭（I'm OK—You're OK 四阶段，ch16）；解药是**加一个"的"字**——看见别人"的"好（那好属于别人，不等于我差），把一切注意力放回自己的成长（ch16）。

## 操作
1. **弹窗+记次数**（ch15）：手机做一件事就设一次"抱怨弹窗"记录——今天抱怨了几次、各关于什么。数量本身就是干预（觉察=卸载）。
2. 每记一次，强制二分法（ch15）：这事能解决吗？能→写下第一个行动，抱怨额度转成任务；不能→写下"我选择承受/绕开"，然后闭嘴。
3. 嫉妒转化练习（ch16）：列 3 个让你不舒服的成功者，每人写出"他身上我真想要的一个具体能力"+一个他为此付过的代价。目标:把比较输出改为清单输入。
4. 鄙视转化练习：对讨厌的人问"他靠什么活成这样的？"——厌恶点往往是自己的盲区或未被满足的需求（ch14 世界有生命的镜子原理互参）。
5. 一周复盘：抱怨次数曲线+转化率（几次转成了行动）。

## 边界
- 戒抱怨≠不维权不表达不满：书针对的是反复宣泄却不改变的模式；正当抗议与谈判不在禁用范围。
- 记次数若滑向自我监控强迫，停止打卡，回到 metacognition 的"为什么"提问。
