# 方法卡 · 贵人与求助（Noble Network）

来源：第 05 辑（ch05，12 条贵人原则全列在该篇笔记）。

## 何时使用
- 用户觉得"没人帮我/没人带我"、人脉焦虑。
- 用户不好意思开口求助，或一开口就是索取姿态。
- 用户抱怨遇到都是白嫖的人。

## 原理
核心翻转：**想遇到贵人，自己先成为贵人**——贵人不是运气，是你创造价值+展示价值后别人的顺势出现（ch05）。求助≠乞讨：求助本质是"正确展示自我价值的交易"，对方帮你有回报预期（金钱/名声/情感/潜在合作）时才帮得痛快（ch05）。12 条原则细节以 ch05 笔记为准（如"大量的人希望看到你成功""正在做正确事情的人更容易获得相助""活在未来的人更容易遇到贵人"等）。

## 操作
1. 先自查清单（ch05 原则逐条对照）：我在做对别人有价值的事吗？我公开表达过吗？我帮过人吗？
2. **重构一次求助**：让用户写出最近不敢开口/开口失败的求助，按"交易结构"重写：我有什么价值→我能给他什么（哪怕是"见证成长"）→帮我的成本对他多低。
3. 主动施助练手：本周先帮一个"以后可能互相成就"的人做一件具体的事（成为贵人的最小行动）。
4. 展示面：把正在做的事公开出来（写作/作品/朋友圈长文），"让正确的事被看见"（与 ch33 写作互参）。
5. 拒绝伸手党行为自查：能 Google 的不问人（ch23/ch24 反复回指），问题质量决定回答质量（ch51）。

## 边界
- 求助交易论不适用于情感关系中的真诚示弱——书谈的是成长/事业场景。
- 不要表演价值：ch05 的前提是"正在做正确的事情"，空壳人设吸引不来贵人，只吸引骗子。
