# 方法卡 · 操作系统升级（概念重写 + 什么更重要）

来源：第 00/18/35/36/39/49/50 辑汇总——本书的元方法。

## 何时使用
- 用户的问题里藏着错误定义（"我没钱所以没机会""坚持没用""时间不够"）。
- 用户决策瘫痪、反复摇摆。
- 教练做任何诊断前的第一步：**先查概念**。

## 原理
本书方法论总纲：**清晰且正确的概念是一切思考的基石**（ch00）。心智=操作系统，其双核=概念（Concept）+价值观（Value）（ch18：命运=你一次次选择的推演结果）。升级三步：
1. **概念重写**：对关键概念问"它到底是什么？它不是什么？"——本书全程示范：财富自由≠有钱、资本≠钱、智商≠天生、速成≠快速成功、坚持≠美德……重写概念即换镜头（ch00/06/12/39/40/49）。
2. **价值观排序**："什么更重要？什么最重要？"（ch49）——一把刀解决学习、择偶、带团队、投资等一切选择问题；价值观=分辨什么最重要（ch18/35）。
3. **添加必要的条件**：二选一纠结时别急着选，先**给选项加限定条件**把题目变可解（亚马逊选书四条件、奥卡姆剃刀、五步纸笔练习在 ch35；该法同样用于"万一还有更好的"型拖延：ch39"短期来看可能有最好的，长期来看只有更好的"＋"现在我知道的最好的只有我现在能想到的这个！"）。

## 操作（教练版流程）
1. 复述用户问题，圈出其中的关键概念（自由/坚持/没时间/聪明…）。
2. 用书中重定义对表（ch00-52 各辑都有对应概念），指出"你在这用的是日常义，书里的定义是××"——这一步常直接消解问题。
3. 让用户对剩余真问题做排序："这里面什么最重要？"只许留一个（ch49）。
4. 需要比较选项时跑 ch35 五步纸笔：写下选项→列"必要条件"（不是加分项）→剔除不满足者→仍平手则选不可逆成本低的那个（ch39 100%安全感在投资处不适用，此处按 ch35）。
5. 把本次结论固化成一条"原则"写进用户的清单，未来同类时刻直接调用并事后复盘（ch50 借《原则》教的做法）。

## 边界
- 概念重写不是诡辩：新定义要"清晰、准确、必要"（ch36 对聪明的定义即标准）。
- 排序一次只留一个"最重要"，贪多即失效。
