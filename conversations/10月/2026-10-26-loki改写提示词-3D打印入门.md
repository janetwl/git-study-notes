## 2. 处理过程

### 第一轮:Agent 工具召唤 _loki

- 通过 Agent 工具(subagent_type: `_loki`)派发原始需求,并附背景设定:中文使用者、几乎零基础、目标是"搞清能做什么/技术路线/预算/第一个项目"
- _loki 返回**第一版提示词**:五章节结构(能与不能 / FDM vs 光固化对比表 / 三档人民币预算+具体机型推荐 / 按周 4 周计划 / 中文资源),附术语解释、劝退观点、价格时效性等语气约束
- 踩坑点:subagent 异步运行,结果经 SendMessage 回传,需转述给用户(代理报告不直接可见)

### 第二轮:SendMessage 续用同一 _loki 会话

- 用 `SendMessage(to: agentId)` 复活上一轮 _loki,指令它**逐条拷问自己**:哪些假设没确认、哪些指令不可执行/诱发幻觉、结构是否过度规定、约束是否互相冲突、遗漏了哪些新手真问题
- _loki 自曝五大弱点:
  1. **擅自假设**:把"想了解"窄化成"入坑购买决策",没问预算/用途/通风条件却要求选型结论
  2. **诱发幻觉**:"推荐目前口碑好的机型"+精确人民币价格——知识有截止日期,指令结构本身在逼模型编数字
  3. **格式配额**:五章节+六维度表格+按周排期,逼出硬填套话
  4. **约束打架**:"篇幅适中" vs 全覆盖;"有明确观点" vs 输入不足=武断
  5. **遗漏隐性需求**:代打服务/创客空间(不买机也能玩)、安全单独讲、失败率等隐藏成本
- 产出**第二版提示词**,核心机制改动:
  - 回答开头**先声明假设**再展开;结论受用途影响处用**分支写法**
  - 价格只给**数量级区间**,禁止精确数字;机型改为**选机标准**(社区量/免调平/耗材开放/售后),历史产品线仅作示范并注明核实
  - "按此结构组织"放宽为"覆盖这些问题,顺序详略可调";篇幅改明确 2000~3000 字 + "深度优先、可省略次要内容"
  - 新增"购机/代打/创客空间三条路径"对比与安全隐患独立成段

### 第三轮:主会话执行第二版提示词

- 按第二版要求输出完整 3D 打印入门讲解:声明假设(数千元预算/可通风角落/网购渠道) → 能与不能(慢、分层向脆、PLA 60°C 软化、表面层纹、失败率) → FDM vs 光固化对比表 + 树脂致敏/通风安全单独强调 → 三条路径对比表("只是好奇先花几十块代打;要玩就买千元级 FDM")→ 数量级预算 → 选机五条标准(Ender 3 / Bambu Lab A1 作历史产品线示例)→ 上手顺序+新手五坑(首层失败是母因/受潮堵头/翘边/裸手碰树脂/第一周钻研参数玄学)→ 资源(MakerWorld、Printables、Thingiverse;TinkerCAD/Fusion 360/Blender;B 站排查关键词)

## 4. 经验小结

1. **"grill 你自己"是有效的提示词迭代手法**:让改写代理批判自己的产物,比再要一版"更好的"更能暴露隐性假设、幻觉诱因(要求实时价格/热销款)、格式配额导致的套话、以及互相冲突的约束。第二版对第一版的每条修改都能对应到一条具体自我批判
2. **防幻觉要改指令结构而非只加免责句**:"给出大致价位区间(数量级即可,不要精确到具体数字)""教选机标准而非推荐目前热销款"——从源头上不再鼓励虚假精确,免责句只是兜底
3. **信息缺失时用"先声明假设+分支写法"**,既保住"一次性完整答案"的偏好,又不逼模型假装知道自己不知道的事
4. **_loki 工作流复用**:SendMessage 复活同一 agentId 可保留其完整上下文(自我批判需要记得自己上一版写了什么);新起 Agent 调用则是白纸
5. 提示词里的"有明确观点"必须配"观点建立在通用原则上,易过时信息标注不确定",否则明确观点=武断

## 附录 A:第二版提示词全文(可直接复制)

```text
你是一位既懂 3D 打印技术、又擅长给新手讲课的导师。我是中文使用者,对 3D 打印几乎零基础:没接触过建模软件,也没见过实体打印机。我的目标是系统了解这个领域——我可能只是好奇,也可能之后想买台打印机入坑,两种情况都请照顾到。

我没有告诉你我的预算、想打印什么、居住环境和购买渠道,所以请你:
- 在回答开头用 2~3 句话列出你对我所做的假设(例如"假设你想打印家居小物和装饰模型、预算数千元、家中有可通风的房间"),然后基于这些假设展开;
- 凡是结论会因用途不同而明显不同的地方,用分支写法:"如果主要想打手办/精细模型 → …;如果主要想打实用的功能件 → …;如果暂时不打算买机器 → …",不要只给一个武断答案。

请用中文回答,覆盖以下问题;顺序和详略你可以按重要性自行调整,不必逐条机械对应:

1. **能与不能**:用几个生活化例子说明 3D 打印适合做什么,并诚实说明它的局限(精度、速度、强度、后处理时间成本、失败率),帮我建立合理预期。
2. **两大家用技术路线**:FDM(熔融沉积)与光固化(LCD/SLA)各自原理一句话、成品效果差异、常用材料、后处理流程,以及各自适合什么用途。安全事项(树脂接触与毒性、通风要求、火灾隐患)请单独说清楚,不要一笔带过。
3. **获得 3D 打印成品的三条路径**:(a) 买一台自己的打印机;(b) 使用按需代打服务(上传模型、收快递成品);(c) 本地创客空间/科技馆体验。比较三者的成本、门槛和适合人群,并告诉我:零基础的人第一步最值得尝试哪条,为什么。
4. **预算**:如果选择购机,按"最低可用 / 舒适入门 / 高端"给出大致的人民币**价位区间**(数量级即可,不要精确到具体数字),并列出耗材和常见辅件的大致开销。请明确注明:价格基于你的训练数据估算,我购买前需自行核实。
5. **选机思路而非具体型号**:不要推荐"目前热销机型"(你的信息可能已过时)。请教给我一套挑选标准(例如:用户社区是否活跃、是否自动调平、售后与配件可得性、耗材是否开放通用),如需举例,请用有多年历史的知名产品系列作为例子,并注明"仅为示范思路,现状需核实"。
6. **入门路径**:给出一个适合新手节奏的通用上手顺序(不必按周硬性排期):组装与调平 → 打印第一个测试件 → 理解切片软件关键参数(层高、填充、支撑)→ 从模型网站下载现成模型打印 → 有余力再尝试新手友好的建模工具。同时指出 3~5 个新手最常见的坑(如翘边、堵头、首层失败)及避坑方法。
7. **学习资源**:适合中文用户的视频平台搜索关键词、社区论坛、模型下载网站;以及打印失败时的通用排查思路和求助方式。

语气与深度要求:
- 面向完全的新手:术语第一次出现时用一句话解释;多用类比,但不牺牲准确性。
- 有明确观点,但把观点建立在"通用原则"上;凡是涉及具体产品、价格等易过时信息,明确标注不确定性,不要假装权威。
- 深度优先于面面俱到:次要内容可以省略,不要为覆盖清单而注水。
- 全文控制在大约 2000~3000 字,多用表格、列表和加粗,方便我快速扫读。
```

## 附录 B:按第二版执行的 3D 打印入门讲解全文

> **我对你的假设**:你大概想打印家居小物、玩具装饰、可能的模型手办;预算上限在数千元内;家里有一个能开窗通风的角落(阳台或书房);购买渠道以淘宝/京东/拼多多为主。如果你的目的只是"了解一门技术"而不想花钱,看第 3 节就够了。

### 一、能做什么,不能做什么

一句话原理:像**挤牙膏**一样,把材料沿着轮廓一层层堆起来,几百层叠出一个立体物件。

**适合**:定制替换件(旋钮、卡扣、支架)、收纳小物、玩具手办原型、教学道具、"网上买不到但我知道要多大"的东西。
**不适合**(诚实预期管理):

- **慢**:小件几十分钟到几小时,大件通宵打印很常见
- **分层方向脆弱**:沿层纹容易掰断,受力功能件要专门设计摆放方向
- **PLA 材料超过 60°C 就软化**——别做夏天车里的摆件、别做热水杯
- **表面天然有层纹**,想达到商品级外观要打磨补土喷漆(时间成本翻倍)
- **失败率高**,学习期一周里总有一两次打印半途报废
- **不适合批量生产**,它是"一件和一百件成本一样"的技术,不是"造一百件很便宜"的技术

### 二、两大技术路线

|  | **FDM 熔融沉积** | **光固化 LCD/SLA** |
|---|---|---|
| 原理 | 加热熔化塑料丝,挤出堆叠 | 紫外光透过屏幕,逐层固化液态树脂 |
| 精度/表面 | 有可见层纹,中等 | 极精细,表面光滑,手办级 |
| 材料 | PLA/PETG/TPU 耗材卷 | 液态树脂(几十种配方) |
| 后处理 | 撕支撑,基本完事 | 异丙醇清洗→紫外线二次固化→去支撑,**三道工序** |
| 省心度 | 高,脏了塞纸巾里也不危险 | 低,全程沾化学品,废液要按有害垃圾处理 |
| 价位量级 | 千元级起步 | 机器略贵,但真正贵在持续买树脂和耗材 |

**⚠️ 安全单独说(光固化)**:液态树脂是**皮肤致敏物**,未固化树脂沾皮肤可能引起越来越严重的过敏——必须戴丁腈手套;固化前的树脂蒸气需要**通风**,密闭卧室不适合;酒精清洗区远离明火。FDM 用 PLA 则安全得多(植物基塑料,打印气味基本无害,但喷嘴 200°C+ 烫伤风险在,打印机工作时别让孩子摸)。

**分支结论**:想打手办/珠宝原型且有可通风空间 → 光固化;其他所有情况、以及"我还没想好打什么" → **FDM**。新手第一台几乎总该是 FDM。

### 三、获得成品的三条路径(很多人漏了后两条)

| 路径 | 单次成本量级 | 门槛 | 适合谁 |
|---|---|---|---|
| **按需代打服务**(传模型→收快递) | 一件几十到几百元 | 零 | 只想要"那个东西",不想玩机器 |
| **买一台 FDM** | 机器千元级 + 慢慢烧耗材 | 要学调平/切片,**过程本身是乐趣** | 决定入坑、享受折腾 |
| **本地创客空间/科技馆体验** | 免费到几十元 | 看你城市有没有 | 先摸一次真机再决定买不买 |

**我的明确观点**:如果你此刻只是好奇——先上淘宝搜"3D打印代打",花几十块打一个桌面摆件,你就知道这门技术值不值得你桌面上多一台机器。**如果你已经确认自己想要的是"玩"而不只是"那个成品",直接买千元级 FDM,不要等"想清楚了"——千元级试错成本已经低到不值得纠结。**

### 四、预算(数量级,具体数字请核实)

- **最低可用**:入门 FDM 整机 **约千元级**;PLA 耗材 **约 50~100 元/公斤**;铲刀、酒精、除胶小工具 **百元级**。合计 1000~1500 这个量级能开始。
- **舒适入门**:**数千元档**——封闭机箱、多色打印套装、耗材烘干机、买几种好耗材。
- **高端**:**万元以上**——工业级 FDM、碳纤维材料、高分辨率大幅面光固化。
- **隐藏成本**:初期 10~20% 的打印会失败(浪费耗材和时间)、断电断料重打、以及最大的成本——**你的时间**。

### 五、选机思路(不推荐"当前热销款",教你看什么)

1. **社区和教程量**:出问题能搜到中文解答的,比机器本身先进重要十倍
2. **免调平/自动校准**:老式手动拧调平旋钮能劝退 80% 新手;优先带自动调平的
3. **耗材是否开放通用**:只用厂家专供耗材的机器,是长期绑架
4. **售后与配件**:喷嘴、热端是消耗件,买得到、换得起
5. **封闭机箱优先**:成功率高、更安全、气味不外溢

可作"示范思路"的历史有名产品线(现状请自行核实):**创想三维 Ender 3 系列**(数百元级、教程海量、适合愿意折腾的人)、**Bambu Lab A1 系列**(千元级、开箱即用体验好、多色生态)。

### 六、上手顺序与新手五坑

**顺序**:拆箱组装+自动调平 → 打印随机附带的测试船/立方体 → 装切片软件搞懂三个参数就够:**层高**(越小越精细越慢)、**填充**(内部网格密度,装饰件 10~15% 即可)、**支撑**(悬空部分需要的临时脚手架,会留疤)→ 下载现成模型直接打 → 有感觉了再学建模(入门首推网页版 **TinkerCAD**,两小时上手;零件类用 Fusion 360;手办类用 Blender)。

**五个坑**:
1. **首层失败是一切失败的母因**——平台不干净/不平,十打九歪。宁可多花 20 分钟重新调平
2. **堵头**:耗材受潮(PLA 吸水)或打印中途降温,耗材开封久了对着热端烘一下再打
3. **翘边**:打印边角从平台翘起脱落——避开穿堂风、用胶水/PEI 平台增加附着力
4. **光固化裸手接触树脂**:从第一天就戴手套,别等过敏了才后悔
5. **第一周就研究参数玄学**:前 10 个模型用默认参数打明白,比看 100 篇"最佳设置"有用

### 七、资源与排查

- **视频**:B 站搜「3D打印 新手入门」「FDM 首层 调平」「光固化 安全」
- **模型库**(下载现成的,不用自己建模就能玩):**MakerWorld**、**Printables**、**Thingiverse**——前两个对中文用户尤其友好
- **切片软件**:Bambu Studio / OrcaSlicer / Cura,都免费
- **打印失败排查顺序**(背下来):**首层附着 → 温度 → 耗材状态 → 机械松动**,四层依次排除;拍失败件的照片发到 B 站评论区或对应品牌社区,中文 3D 打印社区对新手问题回复率很高

**总结观点**:先花几十块代打一个成品验明兴趣 → 确认要玩就买千元级免调平 FDM → 从现成模型开始 → 三个月后再考虑光固化或多色。该省的钱是"一步到位买万元机",该花的钱是"千元级先把乐趣拿到手"。
