# 学升课程音频转写:可行性与方案

来源:分析链接 `https://webapp.songy.info/#/courses/details?course_id=856` 的音频转文字可行性。日期 2026-10-29。

**状态:已归档,暂不执行。** 调研与方案已完成,未开始登录/下载/转写;日后要继续,从文末"修订后的借鉴版路线"第 1 步(浏览器登录拿 token)开始即可。

## 这个链接是什么

- `webapp.songy.info` 是「学升」Flutter Web 应用(简介:学习, 连接, 成长, 升华)。
- URL 中 `#` 后面是前端路由,服务器返回的 HTML 只是空壳,内容由 JS 运行时向后端请求渲染,所以直接抓取看不到课程详情。
- 从其 `main.dart.js` 逆向出真实后端:`https://bandu-api.songy.info`,课程详情接口为 `GET /courses/details?course_id=856`。
- 匿名访问统一返回 `{"code":100400, "cause":"not found"}`,连列表接口也一样 → API 需要登录凭证。

## 登录方式:密码用不上

- 实际流程是手机号 + 短信验证码,没找到账号密码登录入口:
  - `POST /v2/account/captcha` 发送验证码
  - `POST /v2/account/login` 参数:`phone_code / phone_number / captcha_code`
- 可行做法(协作式登录):用户给手机号 → 我调接口触发短信 → 用户回报 6 位验证码 → 我换取 token。全程不接触密码。

## 音频获取:大概率 HLS 流

- 页面加载了 `hls.min.js`,课程音频很可能是 m3u8 切片(一段段 .ts),可能带 AES 加密。
- 需要 token 后才能看到真实地址;拿到后要下载切片、用 ffmpeg 合并转成单个 mp3/wav 才能喂给转写工具。
- 留个后手:课程详情接口的 `course_contents` 字段里可能直接带文字稿,有就省掉转写。

## 本机体检结果(实测)

| 项目 | 实测 | 对转写的影响 |
|---|---|---|
| CPU | i5-1035G1 @1.0GHz(4核8线程,低压) | 本地 Whisper 只能靠它,算力弱 |
| 显卡 | AMD Radeon 630 + Intel 核显 | 没有 CUDA,GPU 加速无望 |
| 内存 | 8 GB | 只能跑 small 级模型,medium 勉强 |
| Python | 3.9 可用 | 能跑 faster-whisper |
| ffmpeg | 未安装 | winget 一条命令可装 |

## 结论:本地转写不划算,推荐云端

- 本地估算:faster-whisper `small` 约 1 小时音频 ≈ 1 小时以上机时,中文质量一般;`medium` 要 3~4 倍时长,8GB 内存还容易爆。
- 云端性价比排序:
  1. 讯飞听见 / 阿里通义听悟 — 中文第一梯队,有免费额度,约 ¥1/小时,网页端可直接上传出带标点文稿;
  2. 腾讯云 / 阿里云 API — 提供 API key 后可全自动:切段上传 → 轮询 → 汇总成 Markdown;
  3. OpenAI Whisper API — 质量不错但要海外支付,约 ¥15/小时,不如前两个划算。

## 附:社区经验帖图片的借鉴分析

来源 `conversations\file.webp`。一位「学升」社区同学的经验:笑来老师课程只有语音,他的路线是"网页套壳成桌面应用 → 先做成课程目录 → 模型转录音 → 模型校对 → 人工校对做成电子书 → 拓展成笔记软件/学升超级插件"。

## 值得借鉴的 4 条

1. **别逆向登录,蹭浏览器会话(最大启发)**:套壳的本质动机是绕开登录难题。等效且更轻的做法——Edge/Chrome 开 `--app` 模式当桌面应用用,登录后从 DevTools 网络面板复制 token,或装"猫抓"类扩展嗅探 m3u8。可省掉"手机号+短信码协作登录"。
2. **转写后加一道"模型校对"**:原方案漏了这层。流水线应为:ASR 粗稿 → LLM 校对(修同音字/术语/分段标点)→ 人工抽查 → 电子书。校对用普通 GPT 级/国产模型就够。
3. **分阶段交付:先目录,再正文**:先拉 856 课程目录做清单,确认音频数量/总时长后再决定转写投入。
4. **"接入 CLI"你已经有了**:Claude Code 就是那个 CLI;转好的文字稿可喂 book2agent 蒸馏成课程专属教练 agent;流程稳定后封装成 `/course2notes` 斜杠命令——就是他说的那个"超级插件",不用自己写软件。

## 泼冷水 1 条

- **套壳桌面应用是绕远路**:壳不解决音频落地和转写,原作者也只做成了目录。直接蹭浏览器会话拿 token/m3u8,比养 Electron/Tauri 壳省事得多。

## 修订后的借鉴版路线(以此为准)

1. 浏览器登录一次 → 复制 token(替代短信协作登录);
2. 只拉 856 课程目录,清点音频数量与总时长;
3. 下载 HLS 切片 → ffmpeg 合并 mp3;
4. ASR 粗转(云端)→ LLM 校对 → 人工抽查 → Markdown 电子书;
5. 成稿喂 book2agent → 课程专属教练 agent;稳定后封装斜杠命令。
